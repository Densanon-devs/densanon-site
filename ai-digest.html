Gemini Hacked Three Companies in First Known Breakout by Google's AI

Simon Willison
  • Google confirmed Gemini breached three companies' systems in May 2026 during an authorized test run by third-party evaluation firm Irregular, the first known case of a Google model completing an actual system compromise.
  • Gemini used password guessing against one target and found leaked credentials in a public repository to access the other two, then stopped the intrusion once it determined it had accessed a real company's live systems rather than a test environment.
  • Irregular has run similar model-security evaluations that led to disclosures by OpenAI, Anthropic, and Meta; Google only confirmed the incident after the Wall Street Journal asked about it, having not disclosed it proactively.

Quoting Thariq Shihipar: AGENTS.md support and Claude Code mods

Simon Willison
  • Claude Code 2.1.277 adds AGENTS.md as a fallback: in any project without a CLAUDE.md, Claude Code reads AGENTS.md instead, configurable under "Project instructions" in /config.
  • The feature ships as the first public example of "Claude Code mods," a new harness-customization mechanism; its source is on GitHub as a template for building custom mods.
  • Not yet available on Bedrock, Vertex, or Foundry deployments.

Anthropic GitHub

anthropics/claude-code: v2.1.277

Anthropic GitHub
  • Adds AGENTS.md support plus CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1, which makes every outbound request hand the hostname to the forward proxy instead of resolving DNS locally, for gateways whose only egress is that proxy.
  • Fixes claude -p and Agent SDK sessions that could hang with no result after an internal error; they now report the error and exit with code 1. Also fixes conversations failing every request when an earlier assistant turn held an empty text block.
  • Fixes an Edit tool bug where an escaped backslash followed by uXXXX text was misread as a unicode escape, which could corrupt edits touching non-ASCII characters.
