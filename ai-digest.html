XYBench: Helping with the problem behind the question

Hugging Face Blog
  • XYBench contains 8,115 questions, mostly programming and everyday tasks, testing whether assistants spot a misconception behind a request.
  • On Stack Overflow questions, models focused mainly on the underlying goal in only 35-41% of responses, less often than human answers.
  • Models chose the goal-focused answer 71-84% of the time when picking between options, so selecting is more reliable than writing.

llama.cpp v1.0.0 : A stronger foundation for the local AI ecosystem

Hugging Face Blog
  • llama.cpp and ggml both reached v1.0.0; future API and ABI breaks will be signaled by major-version bumps.
  • Semantic versioning: MAJOR for breaking C API changes, MINOR for compatible features, backends or model support, PATCH for fixes.
  • Supports 150+ model architecture variants and ships via Docker, Debian, Homebrew, conda-forge, MacPorts, Winget and XCFramework.

Build a Robot Pick-and-Place Simulation with SimReady Assets

Hugging Face Blog
  • Builds a pick-and-place simulation in Isaac Sim 6.2 using a UR17G arm, Robotiq 2F-140 gripper and a beverage can from SimReady Central.
  • SimReady assets are OpenUSD files with simulation properties such as collisions, mass, joints and joint drives.
  • The setup is fixed and scripted with no vision, so it does not show robustness to uncertain object positions or real hardware.
