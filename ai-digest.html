ToyBlocks: A controlled world for robot learning and evaluation

Hugging Face Blog (Ai2)
  • Ai2 describes ToyBlocks as an open simulation framework and the first "FoundationWorld": a robot arm and blocks on a tabletop, designed so researchers can change training data or model design, repeat tests and trace why a robot fails.
  • The initial release includes 85,336 long-horizon demonstrations (nearly 1,600 hours), two trained models (Molmo2-4B-tb and maniflow-tb), plus simulation assets, generators, and training and evaluation code.
  • In the authors' tests, ManiFlow's atomic-skill success was 80.0% in simulation and 81.1% on a physical Franka FR3 arm, while the hierarchical Molmo 2 + ManiFlow system scored 55.5% in simulation and 50.0% (15/30) in the real world; the authors say more trials are needed for statistical confidence.

anthropics/claude-code: v2.1.319

GitHub: anthropics/claude-code
  • Auto mode with telemetry or feature flags off (including behind LLM gateways) now asks about or denies calls the server can't check instead of falling back to the built-in classifier; setting CLAUDE_CODE_AUTO_MODE_SERVER=0 keeps the classifier.
  • The release adds permissions.denyInsteadOfPrompting and fixes a Bash permission bypass via a crafted environment prefix, a sed permission-check skip, and a sandbox escape when creating a worktree.
  • It also adds MCP task support in the terminal, with tasks running in the background and Claude told the result on completion.
