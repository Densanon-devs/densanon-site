Research & Papers

GLM-5.2 is probably the most powerful text-only open weights LLM

Simon Willison
  • Z.ai released GLM-5.2 (753B params, 40 active via MoE) under MIT license — the largest open-weights text model available, comparable to frontier proprietary models.
  • At 1.51TB the model is impractical for most local setups, but the MIT license makes it a meaningful benchmark baseline and a starting point for distillation work.
  • Simon's writeup covers practical context: what it beats, what it does not, and how it fits into the rapidly shifting open-weights landscape.

Beyond LoRA: Can you beat the most popular fine-tuning technique?

Hugging Face Blog
  • HuggingFace's PEFT team compares LoRA head-to-head with newer alternatives (DoRA, VeRA, LoKr, and others) across a range of tasks and model sizes.
  • Findings show no single technique dominates universally — choice of method depends heavily on target task, compute budget, and model architecture.

MolmoMotion: Language-guided 3D motion forecasting

Hugging Face Blog
  • AllenAI extends the Molmo multimodal family to motion forecasting: given a scene and a language instruction, the model predicts physically grounded 3D trajectories.
  • The approach bridges vision-language understanding and robotics planning without requiring task-specific motion datasets, using general VLM pretraining as the foundation.
  • Weights and a demo are available on the HuggingFace Hub, making it accessible for robotics and embodied-AI researchers.

GLM-5.2: Built for Long-Horizon Tasks

Hugging Face Blog
  • Z.ai's own writeup positions GLM-5.2 as a long-context, long-horizon reasoning model, with emphasis on multi-step agentic tasks rather than single-turn benchmarks.
  • The model ships with a 128K context window and instruction-tuned variants optimized for coding, math, and tool-use scenarios.

Quoting Charity Majors

Simon Willison
  • Charity Majors argues the economics of code production inverted in 2025 — generating code became free and instant, collapsing the value placed on individual lines of code.
  • The scarce resource is no longer writing code but understanding, maintaining, and deleting it — shifting what engineers are paid to do.
  • A sharp framing with direct implications for how developer tools and AI coding assistants should be positioned going forward.

MosaicLeaks: Can your research agent keep a secret?

Hugging Face Blog
  • ServiceNow researchers benchmark how much sensitive context research agents inadvertently leak when composing multi-step responses across document sets.
  • Results show current RAG-style agents are prone to cross-document information bleed — a significant concern for enterprise deployments handling confidential data.
  • The paper proposes evaluation metrics and mitigation strategies, including retrieval filtering and output auditing hooks.

Temporary Cloudflare Accounts for AI agents

Simon Willison
  • Cloudflare now supports ephemeral Worker accounts that agents can spin up, use, and tear down programmatically — no persistent credentials required.
  • Simon notes the AI agents branding is largely marketing, but the feature is genuinely useful: sandboxed compute with automatic cleanup prevents orphaned cloud resources.
  • Relevant for anyone building agents that need to run untrusted code or temporary HTTP endpoints in isolated environments.

Simon Willison
