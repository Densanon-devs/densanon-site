Research & Papers

RENDER: Controlling Reader-Facing Evidence in LLM Memory Evaluation

ArXiv cs.AI
  • Introduces RENDER, a benchmark control that holds conversation content fixed while varying only the 'reader-facing artifact' - ChatGPT-style memory entries, LangChain summaries, MemGPT-style typed records, or raw dialogue.
  • Presentation format alone produced 24.6-48.8 point accuracy swings across models, and structured packet formats beat raw dialogue by 42.4-72.6 points.
  • Some models that scored zero on formal ledger-style formats hit 45.4-53.4% accuracy on the same underlying facts shown as natural-language entries - meaning current memory/RAG leaderboards partly measure format sensitivity, not memory quality.

ESQ-Bench: A Multi-Tier Enterprise Oracle Benchmark for Evaluating NL2SQL Dialect Generalization and Silent Semantic Divergence

ArXiv cs.AI
  • Builds an Oracle-focused enterprise NL2SQL benchmark (6 populated schemas, 465 tables, 164,682 rows, 550 validated question-query pairs across 3 complexity tiers) to replace the simplified academic schemas of Spider/BIRD, where models already claim 89%+ accuracy.
  • Claude Sonnet 4.6 held up best across tiers (87.4% / 74.9% / 68.7% execution accuracy), beating GPT-4o's schema-linked approach (79.8% / 60.3% / 57.2%); Llama 3.2 managed only 13.3% overall.
  • Flags 'silent semantic divergence' - queries that execute and return a result but are semantically wrong - affecting 73-99% of nominally successful queries, which plain execution-accuracy scoring completely misses.

LLM Agents Perform Controlled Experiments Using Simulation Models

ArXiv cs.AI
  • Builds an agent framework where an LLM designs and runs controlled experiments against a high-fidelity pharmaceutical process simulation, rather than reasoning in text alone - it constructs tasks, executes comparative simulation runs, interprets outcomes, and issues evidence-based recommendations.
  • Tested in an actual industrial setting, the simulation-integrated approach beat language-only reasoning on output specificity, user-rated correctness, and helpfulness.
  • A concrete example of 'reasoning through intervention' - agents that test hypotheses by manipulating a real system model instead of just pattern-matching plausible-sounding answers.

Does Fine-Tuning Undo Activation Steering? Behavioural Recovery Without Weight-Edit Reversal

ArXiv cs.CL
  • Tested whether baking activation-steering behavior changes directly into a model's weights (a proposed pre-release alignment technique) survives later fine-tuning, across 5 instruction-tuned models from 3B-14B.
  • The steering edit proved mechanistically durable (mean vector recovery rho = 0.004; fine-tuning updates are nearly orthogonal to the steering direction) but functionally fragile - refusal-ablation steering lost 64% of its behavioral effect on average under standard SFT.
  • The weights themselves barely change, but the suppressed behavior comes back anyway through other pathways - so 'align it into the weights before shipping' is not a safe fire-and-forget move once customers fine-tune on top.

The Dialect Tax: Dialectal Biases Persist throughout the Language Modeling Pipeline

ArXiv cs.CL
  • Traces dialectal performance gaps (non-Standard-American-English varieties) across every stage of the LM pipeline - tokenization, pretraining, post-training, and inference - using parallel corpora that are semantically equivalent across dialects.
  • Character-level tokenization does not close the gap, ruling out subword segmentation as the sole culprit; during training, dialect pairs induce more divergent gradient updates than pairs of unrelated Standard-American-English documents.
  • Reward models are inconsistent - sometimes favoring isolated dialectal tokens while penalizing the same dialect features in full context - showing the bias accumulates incrementally across the whole pipeline rather than from one fixable component.

Granite 4.2 LLMs: How They're Built

Hugging Face Blog
  • IBM shipped three dense decoder-only Granite 4.2 models (3B/8B/30B) using grouped-query attention (40 attention heads / 8 KV heads) and RoPE, pretrained on roughly 15 trillion tokens across a five-phase schedule that extends context to 512K tokens.
  • The 8B and 30B models add a multi-stage, multi-environment agentic RL pipeline - training in real sandboxed environments (SWE agent, terminal, web search) so the models practice tool use and code edits, not just SFT on static data.
  • Reported 30B benchmarks: 41.89% on SWE-Bench Multilingual, 89.17% on HMMT Feb25 math, and 81.38% on RULER 128K long-context.

Training and Finetuning Multi-Vector Embedding Models with Sentence Transformers

Hugging Face Blog
  • Walks through training ColBERT-style multi-vector retrievers in Sentence Transformers v6.0 - one small vector per token instead of one vector per document, scored with the MaxSim operator.
  • Finetuning the '-unsupervised' checkpoint of lightonai/mLateOn on 1M MIRIAD medical Q&A pairs adapted far better to the new domain than the fully-supervised sibling checkpoint (+0.0311 NDCG@10 vs. only +0.0042).
  • The finetuned model hit 0.9139 NDCG@10 on a 200K-passage medical retrieval benchmark, beating every zero-shot retriever tested including Qwen3-Embedding-4B (0.7817) and SPLADE-v3 (0.6853) - trained in 14.5 hours on a single RTX 3090.
