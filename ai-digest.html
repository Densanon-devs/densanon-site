Research & Papers

TabletCraft: Bridging a 4,000-Year Cultural Gap with Bidirectional Akkadian NMT and Cuneiform Rendering

ArXiv cs.CL
  • Targets a genuinely under-served NLP problem: half a million surviving cuneiform tablets that almost no modern reader can access, versus the usual English-centric benchmark churn.
  • Builds bidirectional neural machine translation between Akkadian and modern languages plus cuneiform rendering, rather than just transliteration.
  • A useful example of applying current NMT techniques to a low-resource, high-cultural-value language pair outside the standard benchmark treadmill.

MemArena: An Ego-Centric Benchmark for On-Device Agentic Personal Memory Assistants at Scale

ArXiv cs.CL
  • Introduces an ego-centric benchmark specifically for on-device agentic personal-memory assistants handling private, activity-dense interpersonal conversations with open-weight models.
  • Calls out that existing memory benchmarks under-test the combination of activity density, ego-centric perspective, and long-horizon coherence together.
  • Directly applicable to local-first personal-memory assistant work: a ready-made eval axis for on-device memory quality beyond generic long-context benchmarks.

Evaluating OpenAI's Privacy Filter: Cross-Lingual, Cross-Domain PII Detection Across 42 Benchmarks

ArXiv cs.CL
  • First independent evaluation of OpenAI's Privacy Filter (OPF), a compact 1.5B-parameter bidirectional PII detector, across 42 synthetic benchmarks spanning 22 languages and 5 domains.
  • Zero-shot F1 of 0.855 on AI4Privacy sets a concrete reference point for how well a small dedicated PII model performs versus larger general-purpose approaches.
  • Useful benchmark for anyone weighing build-vs-buy on PII redaction for pipelines handling sensitive text.

Tools & Practical

Deploy local agents everywhere with LFM2.5-2.6B

Hugging Face Blog
  • Liquid AI's LFM2.5-2.6B targets on-device agentic AI (tool calling, multi-step workflows) via four post-training stages: SFT on agent data, teacher specialization, multi-domain distillation, and agentic RL inside real agent frameworks.
  • Runs at 220 tok/s on an Apple M5 Max and 113 tok/s on CPU within 2.5GB of memory, pretrained on roughly 34 trillion tokens with a 128K context window.
  • Beats models up to 4x its size on STEM and agentic eval suites (e.g. IFBench 59.17 vs. 34-56 for competitors) — a strong candidate for local tool-calling work.

New release of LLM adds support for reasoning traces, OpenAI Responses, server-side tools, and smarter logging

Simon Willison
  • LLM 0.32 adds visible reasoning-trace display, OpenAI Responses API support, and server-side provider tools in one release — called the most significant update since the initial launch.
  • Redesigns the SQLite logging layer to be content-addressable, changing how prompts/responses get stored and deduplicated.
  • Practical for anyone scripting LLM calls from the CLI/Python who wants reasoning visibility and provider-side tool execution without hand-rolling it.
