ScopeBench: Do Agents Preserve Engagement Boundaries Under Goal Pressure?

ArXiv cs.AI
  • Targets a real deployment risk: autonomous web-app and network pentesting agents where a single out-of-scope action can breach a client's contractual engagement boundary.
  • Notes existing offensive-security benchmarks measure raw hacking capability but not whether agents actually respect scope, the gap ScopeBench is built to fill.
  • Specifically tests whether agents hold to boundaries 'under goal pressure', i.e., when incentivized to complete the task at any cost.

When Is a Multi-Agent Code Judge Actually Grounded? Two Label-Free Measurements, and a Judge That Declines to Guess

ArXiv cs.AI
  • Identifies a core failure mode: LLM code judges return confident verdicts even absent real evidence, indistinguishable from verdicts that were actually grounded.
  • Multi-agent verification doesn't automatically fix this, since compounding ungrounded judges can still look confident.
  • Proposes two label-free measurements plus a judge design that can explicitly decline to guess rather than fabricate a confident verdict.

Stealth Apart, Harm Together: Skill Cascading Attacks on Skill-Based Agent Systems

ArXiv cs.AI
  • Defines the attack surface: a skill is a modular package of natural-language instructions, executable scripts, and reference resources an agent loads at runtime to extend its capabilities.
  • Shows individually-stealthy skill components ('stealth apart') can combine into cascading harm when loaded together ('harm together'), with no single skill tripping detection alone.
  • Directly relevant to any platform that lets agents dynamically load third-party skill packages to extend capabilities.

Auditing and Repairing LLM-as-Judge Failures in a Production Text-to-SQL Pipeline

ArXiv cs.CL
  • Concrete finding: a deployed gpt-4o-mini LLM-as-judge in a production text-to-SQL pipeline agreed with two-author human gold labels at only Cohen's kappa = 0.04, essentially chance-level.
  • Highlights that production LLM-judge setups often ship without ever measuring agreement against human annotators, masking silent quality failures.
  • Framed as an audit-and-repair case study, offering a template for teams to check whether their own LLM-judge is measuring what they think it is.

Not All Memories Are Equal: Hierarchical Collaborative Memory for Validity-Aware Retrieval in LLM Agents

ArXiv cs.CL
  • Distinguishes two memory types in multi-agent team settings: team memory (collective decisions, protocols, consensus) versus individual memory (member-specific observations, execution traces).
  • Motivated by memory being 'heterogeneous and continually evolving', stale or superseded memories need to be distinguished from currently-valid ones via 'validity-aware retrieval'.
  • Proposes a hierarchical retrieval architecture rather than a flat memory store, aimed at LLM agent teams collaborating over time.

A Mechanistic Study of AI-Text Detection Neurons in Frozen BERT: Sparse Probing and Activation Patching on RAID

ArXiv cs.CL
  • Notes AI-text detectors hit high benchmark accuracy, but their internal mechanisms remain poorly understood, an accuracy-vs-interpretability gap.
  • Uses sparse probing and activation patching on a frozen BERT-base-uncased encoder, evaluated on the RAID benchmark, to identify specific neurons responsible for AI-text detection.
  • A mechanistic-interpretability approach applied specifically to the AI-text-detection task rather than general language understanding.
