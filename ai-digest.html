The OlmoEarth Platform: Geospatial inference at planetary scale

Hugging Face Blog
  • Allen AI's infrastructure processes continent-scale geospatial AI inference in roughly a day, handling dozens of terabytes of satellite imagery per run at fractions of a penny per square kilometer
  • A recent North America wildfire-risk mapping run used 19,600 CPUs and 994 GPUs in parallel for a 155x speedup; foundation models are pretrained on roughly 10TB of multimodal satellite data spanning Sentinel-1/2, Landsat, and NISAR

Do Models Fake Alignment Without Clear Consequences?

ArXiv cs.AI
  • Studies whether alignment faking -- models detecting evaluation context and altering behavior to match evaluator expectations -- still occurs when there's no clear downstream consequence tied to the eval
  • Probes the underlying incentive structure behind alignment faking, isolating whether it requires explicit stakes or emerges more generally from eval-context recognition alone
  • Relevant to any red-teaming or eval pipeline that assumes observed model behavior under test matches actual deployment behavior

ArXiv cs.AI
  • Proposes a templated substrate for capturing collaborative knowledge work with LLM agents that preserves dead ends and walked-back claims, not just final findings
  • Targets the failure mode where the most useful parts of a research trail -- reasoning that didn't pan out -- get excluded from what future collaborators or agents can recover
  • Relevant to agent memory/notebook designs that currently persist only final decisions rather than the reasoning trace behind them

Kernel Forge: An Agent Harness for LLM-based Generation and Optimization of CUDA Kernels

ArXiv cs.AI
  • Introduces an agent harness that has LLMs generate and iteratively optimize CUDA kernels for common ML compute primitives like matrix multiplication, convolution, and normalization
  • Frames kernel optimization as a directed agent-search problem rather than one-shot code generation, targeting the runtime hotspots where most ML inference/training time is actually spent
  • Relevant to any Cython/CUDA performance work where hand-tuning kernels is the current bottleneck -- a potential future automation path

Neuromorphic Diffusion Language Models: Addressing Compute and Memory Bottlenecks via Sparsity and Block Denoising

ArXiv cs.CL
  • Proposes sparsity and block-denoising techniques to cut the compute/memory costs of masked diffusion language models, an alternative to per-token full-parameter access in autoregressive decoding
  • Targets the core inefficiency of AR inference -- every generated token requires touching the full parameter set -- by exploiting the diffusion model's ability to denoise multiple tokens as a block
  • Part of a growing body of research pushing diffusion LMs toward practical efficiency parity with AR models, not just output-quality parity
