Welcome Beam: a 501B open model you can own, customize, and scale

Hugging Face Blog
  • Beam is the first open-weight model from US lab Reflection: a sparse mixture-of-experts with 501B total and about 23B active parameters, a 1M-token context window, and an Apache 2.0 license.
  • It targets coding and agentic work; Reflection reports 81.6% on SWE-bench Verified, 80.1% on Terminal Bench v2.1 and 90.6% on GPQA Diamond for the BF16 checkpoint.
  • Checkpoints come in BF16 (about 1 TB), FP8 and NVFP4 (about 280 GB, native on Blackwell GPUs), with day-0 support in Transformers, vLLM and SGLang.

Quoting Addy Osmani, Morgan Westlee Lunt, and Qing Wang

Simon Willison
  • The quoted authors argue that "did a human read the code?" is an imprecise proxy for the real question: what could go wrong with this change, and which check, automated or human, is best placed to catch it.
  • Asking that question also changes when review happens: instead of a gate at the end (write code, open a PR, wait), review moves earlier into the process.

anthropics/claude-code: v2.1.302

Anthropic GitHub
  • Adds CLAUDE_CODE_AUTO_MODE_MODEL to choose the model for the client-side auto mode classifier, and an Idle compaction toggle in /config.
  • Fork subagents are now on by default in claude -p, the Agent SDK, the desktop app and VS Code; set CLAUDE_CODE_FORK_SUBAGENT=0 to turn them off.
  • Fixes include prompt cache misses for tools added mid-session, errors after switching to Vertex or Bedrock mid-session, and file writes on exFAT/FAT32 drives on Windows; startup is faster with many plugins.
