When Retrieval Doesn't Help: A Large-Scale Study of Biomedical RAG

ArXiv cs.CL
  • Large-scale study finds RAG does not reliably improve biomedical QA — gains reported in prior work often disappear under controlled evaluation, and retrieval can actively hurt accuracy.
  • The degradation is strongest when the base model already has solid domain knowledge; noisy retrieved passages introduce conflicting signals rather than grounding answers.
  • Takeaway for practitioners: RAG is not a free accuracy boost in high-stakes domains — retrieval quality and corpus curation matter more than retrieval presence alone.

ArXiv cs.AI
  • Proposes ontology-grounded simulation as a pre-deployment verification layer for enterprise agents — systematically exercising failure modes before production rather than relying on post-deployment monitoring.
  • Introduces a trust-certification framework that generates attestable evidence of agent behavior across defined scenario classes, not just aggregate benchmark scores.
  • Directly addresses the gap between capability benchmarks and deployment readiness that plagues current enterprise agent rollouts.

SaliMory: Orchestrating Cognitive Memory for Conversational Agents

ArXiv cs.CL
  • SaliMory uses salience-weighted memory orchestration rather than raw context expansion — a dedicated module decides what to keep, compress, or discard based on relevance signals.
  • Standard RL training for memory agents degrades reasoning quality; SaliMory separates memory management from the main reasoning path entirely.
  • Outperforms both full-context and naive RAG retrieval approaches on long-session conversational benchmarks.

Consensus is Strategically Insufficient: Reasoning-Trace Disagreement as a Knowledge-Representation Signal

ArXiv cs.AI
  • Challenges the standard multi-agent design goal of minimizing disagreement — argues that on value-laden tasks, divergent reasoning traces are a signal worth preserving, not averaging away.
  • Voting and consensus protocols can suppress genuine normative uncertainty, producing overconfident outputs on questions with no single correct answer.
  • Recommends surfacing disagreement metadata rather than collapsing it, so downstream systems or humans can act on the uncertainty.
