Better Models: Worse Tools

Simon Willison
  • Claude Opus 4.8 was observed injecting invented fields into the nested edits[] array of a tool call that doesn't define those fields.
  • The edit content itself is usually correct, but the extra fields break strict schema validation downstream.
  • A useful reminder that capability gains in newer models don't guarantee better schema discipline — test tool-call fidelity explicitly.

anthropics/claude-code: v2.1.200

Anthropic GitHub
  • AskUserQuestion dialogs no longer auto-continue by default; idle timeout must be explicitly opted into via /config.
  • Default permission mode is now 'Manual' across the CLI, VS Code, and JetBrains — breaking change for workflows that relied on automatic continuation.
  • The --permission-mode manual flag and "defaultMode": "manual" config key are both accepted.

Fable's judgement
