Using Blender with coding agents on macOS

Simon Willison
  • Setup is one step: install the full Blender desktop app from blender.org — no plugin or SDK needed for a coding agent to drive it.
  • Point an agent like ChatGPT Codex at the installed /Applications/Blender binary and prompt it directly (e.g. 'render a scene of a pelican riding a bicycle'); the agent writes and runs Blender's Python API itself.
  • The same workflow produces editable .blend files, rendered stills, or full animations by rendering frame sequences and stitching them with ffmpeg.
