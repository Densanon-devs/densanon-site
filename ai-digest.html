Proxy Confidence: Auditing Black-Box LLM Agents with a Surrogate's Log-Probabilities

ArXiv cs.AI
  • Deployed LLM agents can emit tool calls, queries, and code that are silently wrong before the error surfaces.
  • Frontier chat APIs hide token probabilities, and an agent's stated confidence barely beats chance.
  • The paper proposes auditing such agents using a surrogate model's log-probabilities.

MLLMs Fail to Refuse when Using Tools Agentically

ArXiv cs.AI
  • Agentic multimodal LLMs call tools such as zooming and tagging to push visual reasoning forward.
  • The work uncovers a critical safety failure: these models fail to refuse when using tools agentically.

Training Numerical Intelligence via Auto-Diagnosis and Skill Discovery

ArXiv cs.AI
  • Generating scientific code is not the same as improving the algorithms behind it.
  • For numerical solvers, execution feedback exposes poor performance but rarely reveals its underlying cause.
  • The paper targets training numerical intelligence through auto-diagnosis and skill discovery.

SYNLAT: Syntax-Aligned Text-Latent Compression for Chain-of-Thought Reasoning

ArXiv cs.CL
  • Long chain-of-thought traces impose substantial output-token costs.
  • Under constrained budgets, compression must preserve answer-critical information, making boundary placement central.
  • Token-level and fixed-length boundaries can fragment coherent content; SYNLAT uses syntax-aligned compression.

ArXiv cs.CL
  • Benchmark methodology focuses on the system output, while the reference side gets little attention.
  • The study measures how reference choice moves a score, using the annotation record of a six-language PII benchmark.
