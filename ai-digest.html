Train on prefill, monitor at decode: Using sparse autoencoders for topic monitoring

ArXiv cs.AI
  • Topic monitoring labels the topic of each token in a response during generation.
  • Prior activation-based monitors were trained mostly for harmful content and limited to two or three classes.
  • This work uses sparse autoencoders, training on prefill and monitoring at decode, to broaden topic monitoring.

SELD: Detecting Silent Evidence Loss in Context Compression beyond the Answer

ArXiv cs.CL
  • Context compression is routine for long inputs, but a compressed context only helps if it keeps the evidence for the answer.
  • Existing checks compare the reader model's answer or likely words and miss silent evidence loss.
  • SELD proposes detecting that loss beyond the answer itself.
