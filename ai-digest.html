That leaves one substantive item - Simon Willison promoting datasette-auth-github to 1.0 on the back of a session-expiry bug he hit on his own demo site.

Tools & Practical

datasette-auth-github 1.0

Simon Willison
  • The GitHub login plugin was setting its session cookie without a Max-Age parameter, so the browser treated it as a session cookie and discarded it when the browser closed - which on Mobile Safari meant authenticated sessions kept evaporating. Issue #80 adds the missing Max-Age.
  • The bug surfaced through real use of the agent.datasette.io demo site rather than through tests, a reminder that cookie-lifetime defaults fail silently: nothing errors, users simply get logged out and assume the login is flaky.
  • The 1.0 version bump is a stability signal rather than a feature release - Willison is promoting long-stable plugins to 1.0 - and the release is now tested against both Datasette 0.65.x and the 1.0a series.
