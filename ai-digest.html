datasette #3046: Don't serve link: rel=next HTTP headers to Firefox for HTML pages

Simon Willison
  • Simon Willison noticed in the Firefox network panel that requests to a Datasette table page triggered an HTTP prefetch of the next page of rows.
  • The cause was Datasette's pagination serving a link: rel=next HTTP header.
  • Datasette issue #3046 proposes not serving that header to Firefox for HTML pages.
