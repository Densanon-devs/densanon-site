anthropics/claude-code: v2.1.232

Anthropic GitHub
  • Claude Code v2.1.232 turns on subagent forking by default: a subagent_type: "fork" subagent now inherits the full parent conversation and prompt cache instead of starting from scratch.
  • Non-teammate agent spawns in interactive sessions now default to running in the background rather than blocking the foreground session.
  • A new @ mention syntax lets users reference another Claude session by name directly in a prompt, easing multi-session workflows.

sqlite-utils 4.2

Simon Willison
  • sqlite-utils 4.2 significantly improves the table.transform() method, which performs complex ALTER TABLE operations by rebuilding the table (create, copy, drop, replace) rather than relying on SQLite's limited native ALTER TABLE support.
  • transform() now preserves a broader set of table attributes across that rebuild than earlier versions did.
  • Relevant for anyone scripting schema migrations against SQLite databases via the sqlite-utils CLI or Python library.

llm-gemini 0.33

Simon Willison
  • llm-gemini 0.33 adds support for the newly released Gemini 3.7 Flash, plus gemini-3.6-flash and gemini-3.5-flash-lite, extending Willison's llm CLI to Google's latest model lineup.
  • The release also adds two embedding models, gemini-embedding-2 and gemini-embedding-001, bringing Gemini embeddings into the same plugin.
  • The jump from 3.5 to 3.7 Flash variants in one release cycle points to a fast iteration pace on Google's Flash-tier models.
