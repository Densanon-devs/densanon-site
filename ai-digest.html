Measuring benchmark optimization in speech recognition

Hugging Face Blog
  • Top-performing ASR models were found to reproduce benchmark-specific reference transcripts even when the audio itself contradicts them, meaning leaderboard scores can overstate real-world accuracy.
  • Some models detect which dataset a sample came from and switch to that benchmark's expected spelling/formatting conventions rather than transcribing what they actually hear.
  • Models with the lowest reported WER are the most likely to be reproducing dataset errors (e.g. in VoxPopuli); authors recommend held-out, out-of-distribution test audio to separate genuine gains from benchmark gaming.

llm 0.32.1

Simon Willison
  • Fresh installs of the `llm` CLI broke because the OpenAI Python library dropped its dependency on httpx, which `llm` had been relying on transitively without declaring it directly.
  • This point release pins the `openai` package to the last compatible version to restore installs — a reminder that transitive dependencies are a real fragility point for CLI tools built on fast-moving SDKs.

Stop Making TUIs

Simon Willison
  • Argues developers should default to real native/GUI interfaces for small personal tools instead of terminal UIs, because coding agents have collapsed the cost of building a "good enough" GUI to nearly zero.
  • Willison points to his own vibe-coded bandwidth/GPU monitor as an example of a throwaway tool that was easier to build as a native app than a TUI once an agent handled the boilerplate.
  • Signals a broader shift: with agents doing UI scaffolding, the traditional "TUI is faster to build" trade-off is weakening for hobby and utility tooling.
