Inline rendering with document.currentScript

Simon Willison
  • Lean Rada describes a trick built on the document.currentScript property: a tiny inline script element that replaces itself when the page loads.
  • The example drops in a script that calls document.currentScript.replaceWith(...) so the script tag is swapped for rendered content in place, with no separate container or build step.
