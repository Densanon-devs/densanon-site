AI Morning Digest

OpenAI's new GPT-6 Astra model is the throughline today: it lands as a fresh plugin in the llm CLI and powers two separate vibe-coded demos (a WASM video compressor and a D3 map-projection tool). On the industry side, OpenAI's chief scientist makes a defense-first case for continuing to push capability, a companion piece traces how agentic coding tools reshaped OpenAI's internal research spend this year, and a look at git.kernel.org shows the real infrastructure cost of AI-era scraper traffic.

Product & Industry

Creepy crawlies

Simon Willison
  • Kernel.org maintainer Konstantin Ryabitsev reports git.kernel.org now burns more CPU cycles rendering commit pages for scrapers than it spends on all legitimate access combined, including actual git clones.
  • Across five geographically distributed servers, 14 CPU cores are dedicated just to generating HTML commit views for bots.
  • Willison flags the same exposure for Datasette-hosted sites - any platform serving lots of crawlable pages is vulnerable to this same 'background radiation' of abusive automated traffic, much of it plausibly AI-training scrapers.

Quoting Jakub Pachocki

Simon Willison
  • OpenAI chief scientist Jakub Pachocki argues the strongest case for continuing to train more capable models is defensive: powerful, aligned AI is needed to secure infrastructure and counter rogue agents in real time.
  • He frames it as a balance rather than a blank check for speed, explicitly warning that uncertainty about AI progress does not justify 'racing forward at all costs.'
  • Signals that OpenAI's stated deployment priority is shifting toward defensive and security applications of frontier models, not just raw capability gains.

Research acceleration: The view inside OpenAI

Simon Willison
  • The piece and a companion essay ('An Alien Mind' by Pachocki) both use 'RSI' - Recursive Self-Improvement - as OpenAI's internal framing for AGI progress, without ever spelling out the acronym in the main text.
  • Per-researcher spend on internal coding agents reportedly went from near-zero in February 2026 to about $600 per researcher by late August 2026.
  • The spending curve accelerates sharply in late July, which the author ties to internal researcher access to the model later released publicly as GPT-6 Astra - a concrete signal of how much a stronger model shifted internal agentic workflows.

Tools & Practical

llm 0.35

Simon Willison
  • The llm CLI tool added a plugin for OpenAI's new gpt-6-astra model, so it's callable from the command line alongside every other model llm already supports.
  • It's a minimal release - no other functional changes are called out beyond the new model registration.
  • Keeps llm's pattern of adding new provider models within days of release, so the CLI stays a viable single interface across GPT, Claude, Gemini, and local models.

Video compressor

Simon Willison
  • Willison had Claude Fable 5.1 (in Claude Code for web) build a browser-based video compressor using the WebAssembly build of FFMPEG - all encoding happens client-side, no backend at all.
  • The tool generates 5 preset versions (Largest to Smallest) in about 11.8 seconds, tuning resolution, CRF (22-28), audio bitrate, encoder speed, and H.264 profile per preset.
  • Output compression ratios ranged from 48% to 87% of original size, and the UI shows the exact ffmpeg command behind each version, so results are reproducible rather than a black box.

Mercator <-> Equal Earth

Simon Willison
  • Prompted by the UN's recent vote on the Equal Earth map projection, Willison had GPT-6 Astra (medium) in ChatGPT Work build a D3 tool that animates the transition between Mercator and Equal Earth projections.
  • A slider and play button let users scrub or auto-play the morph between the two projections without hand-coding the projection math.
  • Another data point for GPT-6 Astra's coding ability on a self-contained, math-heavy visualization task done end-to-end via vibe-coding.
