AI Morning Digest

Stateless MCP has recaptured my interest (and inspired mcp-explorer and datasette-mcp)

Simon Willison
  • MCP 2.0 (the 2026-07-28 Model Context Protocol spec) shipped "Stateless MCP," described as the most significant change to the spec since it first launched.
  • The update reignited Simon Willison's interest in the protocol enough to inspire two new projects: mcp-explorer and datasette-mcp.
  • Worth tracking for any project that speaks MCP or is considering adding an MCP surface (e.g., agent tool registries).

smevals - a small eval suite for evaluating models, prompts, and harnesses

Simon Willison
  • Simon Willison, working with Jesse Vincent's Prime Radiant applied AI research lab, released smevals, a small eval suite for testing models, prompts, and harnesses.
  • Positioned as a lightweight tool for answering capability questions across different models rather than a full-scale benchmark.

datasette-agent 0.4a0

Simon Willison
  • datasette-agent 0.4a0 adds a new `await context.browser_task()` mechanism that lets agent tools run code directly in the user's browser.
  • Lets Datasette Agent plugins ship tools that execute custom JavaScript client-side rather than only server-side.
  • An interesting pattern for agent tool design: delegating execution to the browser context instead of the agent's own sandbox.
