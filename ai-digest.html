anthropics/claude-code: v2.1.283

Anthropic GitHub
  • Adds an `x-claude-code-prompt-id` gateway hint header, opt-in via `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`, so LLM gateways can group all requests that serve one user prompt.
  • Adds a new `availableModelsMatch` managed setting; set to "exact", an `availableModels` entry allows only that specific model rather than matching more loosely.
