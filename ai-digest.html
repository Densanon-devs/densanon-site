How We Took Over ChatGPT Accounts

Simon Willison
  • Parameter Labs chained a postMessage handler in the MathLive virtual keyboard (which wrote untrusted input to innerHTML in the parent page) into an unsandboxed iframe, escaping ChatGPT's sandboxed HTML previews.
  • ChatGPT's CSP allowlisted YouTube, and a YouTube oEmbed endpoint could reflect attacker JavaScript, so script ran on the ChatGPT origin and could read private data through the user's own API session.
  • Opening a crafted share link while signed in was enough to exfiltrate data or act as the victim. OpenAI fixed it and paid a $5,000 bounty, which Willison calls a bit cheap.
  • Lesson for anyone building artifact sandboxes: treat every frame's messages as hostile, never pass them to innerHTML, and check each CSP allowlist entry for endpoints that reflect content.
