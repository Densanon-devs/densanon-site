The LLM Proposes, the Executive Disposes: A Self-Verifying Agent Instrument that Dissociates Commitment Drift from Binding Drift in Long-Horizon Agents

ArXiv cs.AI
  • Introduces an agent architecture with a deterministic 'Executive' that owns all belief state, separate from the LLM, so verification is structural rather than dependent on the agent's own self-reports.
  • Explicitly separates 'commitment drift' from 'binding drift' as distinct failure modes in long-horizon agents.
  • Directly addresses the problem of verifying an agent when its own state and self-reports cannot be trusted.
