CoT-Core: Accelerating LLM Evaluation via CoT-Aware Coreset Selection

ArXiv cs.CL
  • Addresses the cost of continuous LLM evaluation by selecting a representative coreset of test cases instead of running full eval suites every iteration.
  • Calls out a 'cold start' bottleneck in existing coreset methods, implying their approach targets faster ramp-up before selection becomes effective.
  • A pattern worth watching for teams running frequent regression benchmarks who want to cut eval turnaround time without losing coverage.

MemoryForge: Synthesize Lifelong Memory for Human-Like LLM Agents

ArXiv cs.CL
  • Critiques static, prompt-injected persona profiles as insufficient for human-like agent behavior in role-play and user-simulation settings.
  • Proposes synthesizing 'lifelong memory' instead of static profiles — a structural alternative to stuffing a persona description into the system prompt.
  • Relevant to any persona-driven agent that currently relies on a fixed character sheet rather than accumulated memory.
