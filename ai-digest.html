If in doubt, delete the uv.lock file

Simon Willison
  • Since moving to Python 3.15, Willison has hit occasional confusing dependency errors, and his rule of thumb is to delete the uv.lock file first.

More Rules, Longer Lists? Benchmarking Self-Evolving Agents on a Hidden-Rule Curriculum

ArXiv cs.AI
  • Self-evolving agents rewrite a persistent state from feedback, but it is largely untested whether this lets them learn a rule nobody told them.
  • An agent can pass by recording each correction as an exception, so its list grows with every new case rather than capturing the underlying rule; the benchmark uses a hidden-rule curriculum to probe this.

Beyond Plausible Prediction: Safety Sufficiency in Web World Models

ArXiv cs.AI
  • Web world models predict the consequences of candidate actions before agents act, but a plausible predicted future does not necessarily support the correct safety decision.
  • The study uses a matched human evaluation of 3,000 predictions from ten frozen models.

CoFiBreak: A Coarse-to-Fine Diversity Reward for Effective Multi-Turn Jailbreak

ArXiv cs.CL
