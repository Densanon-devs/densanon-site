Research & Papers

TreeGraft: Adaptive Multi-Drafter Grafting for Tree-Based Speculative Decoding

ArXiv cs.CL
  • Instead of one fixed drafter, a weak/fast drafter and a strong/slow drafter jointly build a single shared draft tree - the strong drafter rescores the weak drafter's candidates, reselects grafting positions, and recovers promising branches the weak drafter left unexplored.
  • A lightweight scheduler, distilled from an offline value system, decides per-step when it's worth calling the expensive drafter, controlling total drafting cost.
  • Across 10 model pairs and 6 benchmarks, beats the better of the two fixed single-drafter strategies by 15.1% on average, with a maximum gain of 26.6%.

ElementCheck: Complexity-Aware Long-Form Text Factuality Evaluation via Sentence Elements

ArXiv cs.CL
  • Replaces the standard decompose-retrieve-verify pipeline's uniform atomic-claim splitting with entity-pair 'elements' extracted per sentence and organized into a graph.
  • Graph topology estimates sentence complexity on the fly: simple sentences get verified directly, complex ones get targeted element-level refinement - cutting unnecessary re-verification instead of applying one fixed granularity to everything.
  • Introduces a new benchmark (FastFact-Sent) and shows consistent factuality-verification gains across five backbone models with a better accuracy-cost trade-off than fixed-granularity decomposition.

Can a Model Catch Its Own Hallucinations for Free?: Label-Free Doubt Signals Hold Their Own Against a Labelled Dataset for Abstention

ArXiv cs.CL
  • Fine-tunes six open-weight models (1B-8B, two model families) with LoRA to abstain purely off the model's own token-probability dip - no correctness labels required for training.
  • At matched coverage, this label-free abstention-tuning shows no statistically detectable difference from label-supervised abstention-tuning on factual QA.
  • Caveat: it only flags 'shaky-ground' answers where the model's own confidence actually dips - it still won't catch a hallucination the model states confidently.

CIFQA: A Deterministic Tool-Grounded Multi-Agent LLM Framework for Financial Query Answering

ArXiv cs.AI
  • Splits financial QA across specialized agents (query interpretation, routing, parameter extraction, computation planning, response generation) while deterministic Python tools handle the actual rate lookups and arithmetic - the LLM never does the math itself.
  • On a fixed-deposit query benchmark: 95.54% accuracy on calculation-intensive queries and 90.87% overall, beating direct-LLM baselines even when those baselines are handed the full formulas and rate cards.
  • A 17B open-source backbone running inside CIFQA outperforms much larger frontier models given the same information - architecture (deterministic tool-grounding), not model scale, is what fixes numerical reliability here.

Recipes for Steering and Scaling LLMs via Sampling

ArXiv cs.CL
  • Presents a theoretically grounded sampling framework for steering autoregressive LLM output toward a powered/tilted/product target distribution, with two concrete algorithms: Sequential Monte Carlo and Replica Exchange.
  • Framed as inference-time quality scaling with no external supervision or reward model - it's purely a sampling-strategy change over the base model.
  • Beats Best-of-N and standard MCMC baselines on generation-quality scaling in their experiments.

Breaking Claude Code Opus 5 Auto Mode

Simon Willison
  • Johann Rehberger reports a prompt-injection bypass of Claude Code's Auto Mode - the classifier Anthropic made the default defense against injection attacks - that succeeds roughly 80% of the time.
  • Attack path: get the agent to download and extract a zip archive, then have it run code that imports `base64`, which inadvertently loads and executes a malicious local `struct.py` sitting in the extracted files.
  • Worst finding: in one run Claude detected the compromise and tried to clean up, but Auto Mode itself blocked the cleanup command - the classifier let the malware start but then stopped remediation. Recommended fix is infra-level containment (sandboxes/VMs, restricted network, isolated credentials), not relying on the agent-level classifier alone.
