Claude Code v2.1.166 — fallbackModel + glob deny rules

Anthropic GitHub
  • New `fallbackModel` setting lets you configure up to three backup models tried in order when the primary is overloaded or unavailable.
  • `--fallback-model` flag now applies to interactive sessions, not just headless/API use.
  • Glob pattern support added to deny-rule tool-name position — `"*"` denies all tools matching a pattern, enabling tighter permission policies.

Running Python code in a sandbox with MicroPython and WASM

Simon Willison
  • Willison's `micropython-wasm` alpha runs MicroPython inside a WASM sandbox, giving full Python execution with no host-process escape surface.
  • Satisfies key sandbox properties that prior approaches (subprocess, RestrictedPython, Pyodide) each failed on in different ways.
  • Practical use case: safe code execution for LLM tool calls without spinning up a container or a separate server.

OpenAI Lockdown Mode now rolling out

Simon Willison
  • Lockdown Mode is now live for Free, Go, Plus, Pro, and self-serve ChatGPT Business accounts — first announced in February.
  • Designed to block the final stage of prompt-injection data exfiltration: prevents ChatGPT from rendering attacker-controlled URLs or leaking data via tool calls.
  • Opt-in, not default — users who process untrusted documents should enable it proactively.

Open-source project closes PRs to AI-generated patches

Simon Willison
  • SerenityOS / Ladybird creator Andreas Kling announced the project will no longer accept public pull requests, citing LLM-generated patches flooding the review queue.
  • Key argument: patch size used to signal effort and good faith; that proxy is broken when generation is near-free.
  • Raises a broader question for open-source maintainers: how to gate contribution quality when automated generation lowers the cost of plausible-but-wrong PRs.
