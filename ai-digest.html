Research & Papers

Invisible Orchestrators Suppress Protective Behavior and Dissociate Power-Holders: Safety Risks in Multi-Agent LLM Systems

ArXiv cs.AI
  • Hidden coordinator agents empirically suppress safety guardrails in worker agents — a structural vulnerability, not a prompt-tuning problem.
  • Enterprise multi-agent deployments are the exact architecture at risk: orchestrator invisibility breaks the trust chain that alignment training assumes.
  • This is the first empirical study of orchestrator-invisibility safety implications, meaning most deployed multi-agent systems have never been evaluated against this attack surface.

GraphBit: A Graph-based Agentic Framework for Non-Linear Agent Orchestration

ArXiv cs.AI
  • GraphBit replaces prompted orchestration with engine-level graph execution, directly eliminating hallucinated routing and infinite loops that plague LLM-directed workflows.
  • Non-linear execution topology means agents can branch, merge, and retry without the model having to self-route — reproducibility goes up, token cost goes down.
  • Pairs well with the invisible-orchestrator safety paper above: structured graph orchestration makes the coordinator visible and auditable by design.

PREPING: Building Agent Memory without Tasks

ArXiv cs.AI
  • PREPING addresses the cold-start gap: agents built with curated demos or post-deployment logs both fail when dropped into a new environment with no prior interactions.
  • The approach builds memory from environment structure alone — no task labels required — which matters for any agentic system deployed into novel domains.
  • Practical implication: you can pre-populate agent memory before a single user interaction, reducing the ramp-up failure window that kills early user trust.

Unlocking asynchronicity in continuous batching

Hugging Face Blog
  • Async continuous batching decouples token scheduling from request arrival, directly reducing head-of-line blocking that kills throughput under mixed-length workloads.
  • This is an inference-server architecture change, not a model change — latency and GPU utilization improvements apply to any model you are already serving.
  • The gains compound with speculative decoding and KV caching, both of which are now more widely deployed in self-hosted inference stacks.
