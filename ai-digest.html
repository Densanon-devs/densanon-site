CORS Chat

Simon Willison
  • A single-page web UI for exercising any OpenAI-Responses-compatible chat endpoint — no install, runs entirely in the browser against whatever host you point it at.
  • Built to test Qwen 3.8 27B served from LM Studio across two very different machines (an M5 MacBook Pro and an NVIDIA DGX Spark), which is exactly the cross-hardware sanity check local-inference work usually lacks.
  • The catch is in the name: your local server has to be started with CORS enabled (LM Studio's --cors flag) before a browser-hosted client can talk to it at all.
  • The broader pattern is worth stealing — a zero-dependency browser client is a faster smoke test for a local endpoint than another Python script, and it verifies the network path rather than just the model.

Claude Agent SDK for Python v0.2.139

Anthropic GitHub
  • Two releases in as many days (v0.2.138 and v0.2.139), both bundling newer Claude CLI builds — 2.1.232 and 2.1.233 respectively.
  • No API surface changes in either; these are pure CLI-passthrough bumps, so upgrading is low-risk for anything already pinned to the 0.2.x line.
  • The cadence itself is the signal: if you depend on this SDK, pin an exact version rather than a range, because the bundled CLI moves underneath you on a near-daily basis.
  • Available as usual via pip install claude-agent-sdk==0.2.139.
