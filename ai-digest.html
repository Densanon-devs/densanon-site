Research & Papers

AURA: Action-Gated Memory for Robot Policies at Constant VRAM

ArXiv cs.AI
  • Standard KV-cache grows unboundedly in long-horizon embodied tasks; AURA replaces it with an action-gated memory that evicts irrelevant context and holds VRAM flat regardless of episode length.
  • The gating mechanism keys on predicted action relevance rather than recency, meaning the model retains perceptually important frames even when they occurred many timesteps ago.
  • This makes deployment of policy models on edge hardware (robots, edge GPUs) feasible for tasks measured in minutes rather than seconds.

Visual Graph Scaffolds for Structural Reasoning in Large Language Models

ArXiv cs.AI
  • The paper argues graphs are useful not just as external knowledge bases but as structural scaffolds baked into the prompt to guide multi-hop reasoning chains.
  • Providing graph topology at inference time (not only at retrieval time) lets LLMs exploit relational structure even when no external KB is available.
  • Results show improvements on structured reasoning benchmarks without any fine-tuning, suggesting this is a prompt-engineering technique applicable to existing models.

Direct Preference Optimization Beyond Chatbots

Hugging Face Blog
  • DPO is typically framed for chat alignment, but this post extends the technique to non-dialogue tasks such as code generation, summarization, and structured output fidelity.
  • The key insight is that preference pairs for non-chat tasks can be constructed programmatically (e.g., unit-test pass/fail, ROUGE delta) rather than requiring human raters.
  • This broadens DPO applicability to any task where a cheap automated signal can distinguish better from worse completions.

Microsoft's new MAI models

Simon Willison
  • MAI-Thinking-1 is a 1T-parameter sparse reasoning model with 35B active parameters, currently restricted to select early partners — Microsoft's first publicly disclosed frontier reasoning model.
  • MAI-Code-1-Flash is a 137B/5B-active MoE model purpose-built for GitHub Copilot and VS Code, targeting high throughput at lower cost than dense alternatives.
  • Both models use mixture-of-experts architectures, signaling that Microsoft's in-house model strategy is converging on sparse activation for both reasoning and coding workloads.

Uber Caps Usage of AI Tools Like Claude Code to Manage Costs

Simon Willison
  • Uber exhausted its entire 2026 AI tooling budget in four months, driven primarily by token-burning coding agents like Claude Code running at scale across engineering teams.
  • The root cause is that 2025-era budget forecasts had no way to predict the explosive token consumption patterns of agentic coding workflows.
  • This is an early-warning signal for any engineering org deploying coding agents: per-seat licensing models dramatically underestimate actual API spend.

Hackers Simply Asked Meta AI to Give Them Access to High-Profile Instagram Accounts. It Worked

Simon Willison
  • Attackers used straightforward social engineering — no jailbreak, no adversarial suffix — to convince Meta's AI support bot to transfer account access to a target Instagram profile.
  • The exploit is verified from multiple independent sources, confirming this is a real-world, repeatable safety failure in a production AI system with account-level permissions.

Holo3.1: Fast & Local Computer Use Agents

Hugging Face Blog
  • Holo3.1 is a locally runnable computer-use agent model targeting real-time desktop interaction, positioned as a privacy-preserving alternative to cloud-hosted computer-use APIs.
  • The model is optimized for speed on consumer-grade hardware, with inference latency low enough to support interactive GUI automation loops.
  • Local computer-use agents reduce round-trip latency to near zero versus cloud APIs, which is critical for tasks requiring rapid screen-read-act cycles.

Introducing Mellum2: A 12B Mixture-of-Experts Model by JetBrains

Hugging Face Blog
  • Mellum2 is JetBrains' second-generation code-focused MoE model at 12B total parameters, designed to run efficiently inside IDE plugins with low activation cost.
  • The MoE architecture lets it specialize expert routing per language or task type, which JetBrains claims improves completion quality on polyglot codebases.

Adding MCP Tools to Reachy Mini

Hugging Face Blog
  • The post demonstrates wiring Model Context Protocol (MCP) tool servers directly into a physical desktop robot (Reachy Mini), giving the robot LLM-callable tools over a standard protocol.
  • MCP's server-client abstraction means the same tool definitions used in desktop coding agents can be reused verbatim for embodied robot control with no protocol translation layer.
  • This is a practical proof-of-concept that MCP is viable beyond chatbot UIs — it works as a general-purpose LLM-to-hardware integration layer.

Beyond LLMs: Why Scalable Enterprise AI Adoption Depends on Agent Logic

Hugging Face Blog
  • IBM Research argues that raw LLM capability is no longer the bottleneck for enterprise AI; the limiting factor is the orchestration and decision logic that surrounds the model.
  • Scalable adoption requires agents that can decompose tasks, handle failures gracefully, and integrate with existing enterprise APIs without human-in-the-loop at every step.
  • The post distinguishes reactive agents (single-shot tool call) from deliberative agents (multi-step planning with state), recommending deliberative architectures for high-value enterprise workflows.
