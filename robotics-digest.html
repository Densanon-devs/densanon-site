Research & Papers

CLAW: Learning Continuous Latent Action World Models via Adversarial Latent Regularization

ArXiv cs.RO
  • CLAW learns a world model entirely from action-free video using adversarial latent regularization — no robot-collected teleoperation data required.
  • The framework is end-to-end self-supervised and diffusion-based, producing continuous latent action representations that can be decoded into physical commands.
  • Removes the labeling bottleneck that currently limits how much video data can be used to train manipulation policies.

CADET: A Modular Platform for Evaluating Distributed Cooperative Autonomy in Connected Autonomous Vehicles

ArXiv cs.RO
  • Breaks the monolithic onboard-compute assumption: perception, planning, and control are split across networked nodes and evaluated as a distributed system.
  • Designed specifically to surface failure modes that only appear when multiple AVs coordinate — single-vehicle simulators miss these.
  • Modular architecture lets researchers swap individual pipeline stages without rebuilding the full evaluation harness.

AgenticDiffusion: Agentic Diffusion-based Path Planning for Vision-Based UAV Navigation

ArXiv cs.RO
  • Replaces single-view indoor UAV navigation with a multi-view agentic loop that builds scene understanding before committing to a trajectory.
  • Diffusion-based planner generates trajectories that degrade gracefully under limited field-of-view — a common real-world constraint.
  • Agentic loop allows mid-flight re-planning without a full reset, unlike prior feed-forward navigation stacks.

Selecting haptic guidance models in teleoperation: guidelines from a comparative user study

ArXiv cs.RO
  • Provides a unified formulation across haptic guidance models so task-appropriate force-feedback can be selected systematically, not by trial-and-error.
  • User study shows guidance model choice is highly task-dependent — a single default model degrades performance on half the tested scenarios.
  • Practical output is a decision guide: given task type and environment, pick the model class that minimizes operator error.

Interview with CreateMe CEO: Physical AI could transform the way clothes are made

Robotics & Automation News
