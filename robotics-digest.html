Schaeffler plans to mass produce gearboxes for humanoid robots in 2027

The Robot Report
  • Schaeffler, a major automotive-parts supplier, is retooling to mass-produce strain-wave (harmonic) gearboxes for humanoid actuators using a new forming technology, targeting 2027 production.
  • Signals traditional auto-supply-chain manufacturers moving into humanoid component production -- a sign the actuator supply chain is industrializing beyond small-batch specialty makers.
  • Strain-wave gearboxes are currently a key cost/availability constraint on humanoid actuators; mass production at automotive scale could meaningfully lower humanoid unit costs.

Should robot software have execution authorization separate from deployment?

ROS Discourse
  • Introduces RLSOK, an open-source layer that separates 'software deployed' from 'software still authorized to act,' so a revoked release can be blocked from causing physical action even while still installed and running.
  • Addresses a real safety gap: today's typical deployment model conflates installing code with permission to execute it, meaning a recalled release can keep controlling hardware.
  • Part of a broader pattern this week (see Sonny and NXS) of the community bolting safety and architecture layers onto ROS 2 rather than waiting on core changes.

NXS – ROS 2 topics for GMSL2/3 cameras and CAN-FD/serial sensors, no custom bridge

ROS Discourse
  • NXS sits between sensors (GMSL2/3 cameras, CAN-FD/serial) and host compute, exposing them directly as ROS 2 topics without writing custom bridge code.
  • Targets a specific integration pain point: getting sensor data back reliably when compute is mounted far from the sensor, while avoiding node timing/sync fights.
  • Cuts per-project integration overhead for robot builders who otherwise write bespoke bridge code for each sensor type.
