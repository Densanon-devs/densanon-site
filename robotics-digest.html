Research & Papers

SC$^{2}$-WM: A Self-Correcting World Model with Closed-Loop Feedback for Vision-and-Language Navigation in Continuous Environments

ArXiv cs.RO
  • Targets Vision-and-Language Navigation in Continuous Environments (VLN-CE), where agents must make fine-grained navigation decisions under partial observability.
  • Identifies that most existing VLN-CE methods rely on open-loop execution with no mechanism to detect or correct errors mid-task.
  • Proposes a self-correcting world model with closed-loop feedback to catch and fix navigation errors during execution rather than after failure.

Self Supervised Learning from Automatically Generated Demonstrations for Visual Robotic Manipulation

ArXiv cs.RO
  • Targets a core manipulation bottleneck: object-specific programming, manual data annotation, and calibrated perception pipelines slow real-world deployment.
  • Proposes learning from demonstration as a faster alternative to hand-engineered pipelines, but automates demonstration generation instead of relying on costly human-collected data.
  • Uses self-supervision to cut the labeling burden for training visual manipulation policies.

You Don't Need To Stay in The Loop: An Agentic Robotics Loop for Robot-Policy Improvement

ArXiv cs.RO
  • Ports the software coding-agent architecture behind Claude Code and Codex — a main agent orchestrating subagents and tools — directly to robot-policy improvement.
  • Frames robot-policy iteration as a closed loop where a manager agent, analysis subagents, and execution tools replace manual policy tuning.
  • Notable as an explicit design-pattern transfer from agentic coding tools into embodied robotics workflows.
