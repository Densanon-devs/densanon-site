Understanding Asynchronous Inference Methods for Vision-Language-Action Models

ArXiv cs.RO
  • VLA models suffer observation staleness when actions are executed asynchronously — this paper surveys and unifies the concurrent methods proposed to address it.
  • Delayed observations during async execution can cause compounding control errors in real-time manipulation tasks.
  • Provides a unified framework for comparing latency-mitigation strategies across different VLA architectures.

Failing Forward: Adaptive Failure-Informed Learning for Vision-Language-Action Models

ArXiv cs.RO
  • Standard VLA training relies on success-only behavioral cloning, leaving models brittle when small execution errors compound.
  • This work introduces failure-informed learning that uses failed rollouts as corrective training signal rather than discarding them.
  • Improves manipulation robustness without requiring additional human demonstrations, making training data more efficient.

Hierarchical Prompting with Dual LLM Modules for Robotic Task and Motion Planning

ArXiv cs.RO
  • A two-LLM architecture splits high-level task planning from low-level motion planning, improving natural language instruction handling in service robots.
  • Hierarchical prompting reduces the semantic gap between language commands and executable robot actions.
  • Each LLM specializes independently, enabling more intuitive human-robot interaction in assistance scenarios.

How to teach the same skill to different robots

Robohub
  • EPFL LASA researchers tackle skill transfer across robots with different kinematics — currently, upgrading a fleet means reprogramming tasks entirely from scratch.
  • The approach encodes manipulation skills in a robot-agnostic representation that can be retargeted to new hardware.
  • Demonstrated on assembly-line tasks, reducing the cost of migrating skills when deploying or upgrading industrial robot fleets.
