The Robot Report

Building a runtime audit layer for mobile robots as EU AI Act logging / human oversight requirements approach

r/robotics
  • A developer is building runtime_integrity (formerly ros2_kinematic_guard), an open-source ROS 2 middleware that detects when a robot's physical execution diverges from its commanded state.
  • The project targets EU AI Act compliance requirements around runtime accountability and human oversight for autonomous mobile systems.
  • Addresses a real gap: a robot can receive valid commands while its physical execution has already gone wrong — logging command validity alone is not sufficient.
