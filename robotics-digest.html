Research & Papers

RoboSynChallenge: Mastering Real-World Dexterity via Generalizing Synthesized Manipulation Skills

ArXiv cs.RO
  • Targets generalizable robotic manipulation, a persistent bottleneck in embodied AI research.
  • Frames the core limitation as scarce and narrow real-world training data rather than model architecture.
  • Proposes synthesizing manipulation skills that generalize rather than relying solely on collected demonstrations.

FUSE: Active Functional Affordance Grounding through Adaptive Semantic-Geometric Evidence Acquisition

ArXiv cs.RO
  • Addresses function-based object interaction (what an object can be used for) instead of identity-based recognition.
  • Introduces active perception: the agent seeks additional observations when functional evidence is ambiguous.
  • Combines semantic and geometric evidence rather than relying on either alone, aimed at improving affordance grounding accuracy.
Read full article

SAP-Nav: Spatial Semantic Representation Meets Active Perception for Hierarchical Open-Vocabulary Object Navigation

ArXiv cs.RO
  • Tackles open-vocabulary navigation where instructions can reference scene-, room-, region-, or instance-level cues in unseen environments.
  • Builds on and extends prior work (LangMap) with a hierarchical spatial-semantic representation.
  • Pairs the representation with active perception, so the agent adapts what it looks for as it explores.

Attune: A Self-Annotation Tool for Understanding Robot Operator Attention Profiles

ArXiv cs.RO
  • Focuses on the human side of robotics: how operators supervise multiple robots in a fleet simultaneously.
  • Introduces a self-annotation tool to study where and how operator attention is allocated across robots.
  • Positions attention management as a fundamental design challenge for multi-robot supervision interfaces as fleets scale.
