Today's robotics research leans hard into manipulation hardware and perception: two new bimanual/dexterous-hand platforms (AthenaZero, DITTO) and a fully spiking event-camera model (REACT) all target the low-latency, high-fidelity control gap in dynamic manipulation. Research & Papers

AthenaZero: A low-inertia, bimanual robot for dynamic manipulation

ArXiv cs.RO
  • AthenaZero is a bimanual manipulator built to minimize end-effector inertia without sacrificing control authority, using quasi-direct-drive actuation.
  • Transmission remotization moves actuator mass off the distal links, giving the endpoint an effective mass comparable to much lighter reference arms while preserving torque bandwidth.
  • Low endpoint inertia matters for dynamic manipulation tasks involving fast contact or impact, where high-inertia arms risk instability or damage on contact.

DITTO: Dexterous Interface for Transparent TeleOperation

ArXiv cs.RO
  • DITTO targets data collection for high-DOF dexterous-hand manipulation, an area where existing teleop interfaces trade motion-capture fidelity against rendering contact interactions.
  • It aims to capture rich hand motion while still conveying the contact forces needed for precise manipulation, a gap neither pure motion-capture nor haptic-only rigs close well.
  • Better teleop data-collection pipelines feed directly into imitation-learning datasets for dexterous hands, currently a bottleneck for robot learning.

REACT: A Fully Spiking State-Space Model for Real-Time Event-Driven Temporal Perception

ArXiv cs.RO
  • REACT pairs spiking neural networks with a state-space model architecture to process event-camera data natively, instead of converting asynchronous events into fixed-rate frames first.
  • Event cameras deliver microsecond-resolution, asynchronous sensing, but most learning pipelines discard that advantage by accumulating events into frames before inference.
  • A fully spiking SSM keeps the perception pipeline continuous end-to-end, better exploiting event cameras' low latency and power draw for real-time robot perception.

Designing long-travel axes: When rack and pinion outperforms ball screws and linear motors

The Robot Report
  • Past a certain travel length, rack-and-pinion drives can beat ball screws and linear motors on speed, precision, scalability, and cost.
  • Ball screws hit practical length limits from critical speed and screw whip; linear motors solve travel length but add cost and thermal/EMI tradeoffs.
  • Axis technology selection is framed as a system-level tradeoff engineers should re-evaluate per application rather than defaulting to one drive type.

The evolution of Digit: Agility Robotics' journey from Cassie to Digit 5

The Robot Report
  • Agility Robotics' humanoid lineage runs from the research biped Cassie through five iterations of Digit, each retargeted toward industrial warehouse tasks rather than pure locomotion research.

AssemblyGrid v1: benchmarking multi-robot production, handoffs, coalitions, and concurrency

ROS Discourse
  • AssemblyGrid v1 is a new open benchmark for decentralized multi-robot production that explicitly models handoffs, coalitions, and concurrency instead of abstracting them away.
  • The stated motivation is that existing multi-agent/multi-robot benchmarks skip interactions that matter in real production systems, so results don't transfer well to factory-floor coordination.
  • A standardized benchmark lets researchers compare multi-robot scheduling and coordination algorithms on a common, more realistic task set.

Native ROS 2 on Zephyr with Cyclone DDS

ROS Discourse
  • A developer got the standard ROS 2 C client stack (rclc -> rcl -> rmw_cyclonedds_c -> Cyclone DDS) running natively on Zephyr RTOS on an ESP32-S3 over Wi-Fi.
  • The board joins the DDS/RTPS network directly as a native ROS 2 node, skipping the Micro-XRCE-DDS bridge most embedded ROS 2 setups rely on.
  • Removing the bridge layer simplifies embedded robotics architectures and could lower latency and overhead for microcontroller nodes talking to full ROS 2 graphs.

Rosbag2 dynamic recorder (dynrec)

ROS Discourse
  • dynrec is a new tool that makes rosbag2 recording reconfigurable on the fly, for cases where the set of topics being debugged changes often across exercises or robots.
  • It grew out of a real teaching workflow, an undergraduate ROS 2 course, where reconfiguring static rosbag2 setups for each debugging session was tedious.
  • Dynamic topic selection for bag recording cuts the friction of ad hoc debugging across heterogeneous robot setups without restarting the recording pipeline.
