Today's robotics digest centers on embodied AI research: coding agents that refine robot programs from feedback, whole-body humanoid dexterity, memory for embodied agents, and learning manipulation from synthetic video. Research & Papers

Fly-by-Code: Embodied Coding Agents for Aerial Manipulation with Active Visual and Physical Feedback

ArXiv cs.RO
  • Embodied coding agents build robot policies from natural-language instructions by generating executable programs and refining them from execution feedback.
  • The paper targets aerial manipulation and questions the assumption that execution feedback alone reveals whether a task succeeded, adding active visual and physical feedback.

PanTact: Teaching Whole-Body Dexterity with a Wearable Contact Interface

ArXiv cs.RO
  • Humanoids have many degrees of freedom and contact surfaces, but most loco-manipulation research limits manipulation to the hands.
  • PanTact is a wearable contact interface meant to extend manipulation to other body contacts with the environment.

What Should Embodied Agents Remember? Benchmarking and Evaluating Memory Modality for Embodied Agents

ArXiv cs.RO
  • LLM agents typically store past experience as text, but embodied agents also deal with visual and spatial observations, which widens the choice of memory modality.
  • The paper benchmarks and evaluates which memory modalities work best for agents that control robots.

CASTER: Formalizing Zero-Shot Manipulation from Synthetic Videos as Constrained Optimization

ArXiv cs.RO
  • Learning from humans usually needs real demonstrations; video generation models now allow prompting synthetic videos of the task instead.
  • CASTER formalizes zero-shot manipulation from those synthetic videos as a constrained optimization problem.

Graph-Based Heuristics for Minimum Constraint Removal in Cluttered Robot Motion Planning

ArXiv cs.RO
  • Humanoid and service robots in cluttered human spaces can face motion planning problems that are infeasible if every object is treated as a fixed obstacle.
  • The paper proposes graph-based heuristics for the Minimum Constraint Removal problem, which asks which obstacles must be moved or removed to make a plan feasible.

Humanoid robots can sprint and box – but the real test is doing the laundry

Robohub
  • At the World Humanoid Robot Games 2026 in Beijing, robots sprinted, boxed, played football and tackled factory, restaurant and emergency-inspired tasks.
  • The robot Tiangong Ultra completed the 100 metres in 8.64 seconds.
  • The author, Wai-keung Fung of Cardiff Metropolitan University, argues the real test is everyday chores like laundry.
