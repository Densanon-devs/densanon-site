JAMB: Joint Action-Motion Diffusion for Bimanual Manipulation

ArXiv cs.RO
  • JAMB jointly models actions and motion for two-arm manipulation, where each arm’s movement changes the shared 3D scene the other arm must react to.
  • Addresses a gap in most diffusion policies, which generate actions without explicitly modeling how one arm geometrically affects the other.
  • Pushes toward scene-aware, coordinated multi-arm manipulation instead of treating each arm independently.

Learning to Plan in Human-Robot Collaboration: Multimodal Reinforcement Learning for Adaptive Interaction

ArXiv cs.RO
  • Targets assistive robots for older adults and people with disabilities, where effective collaboration on shared tasks is the core requirement.
  • Introduces a multimodal RL approach for the interaction manager that observes the task and infers user/task state to plan next actions.
  • Positions adaptive interaction planning, not just manipulation skill, as the key bottleneck for practical assistive-robot deployment.

Qualcomm to acquire PickNik Robotics and keep MoveIt open-source

The Robot Report
  • Qualcomm is acquiring PickNik Robotics, the team behind the widely-used MoveIt motion-planning framework for robotic arms.
  • MoveIt will stay open-source after the acquisition, easing vendor lock-in concerns for the ROS community.
