Valve overhauls tag system on Steam to improve game discoverability

GamesIndustry.biz
  • Valve added 17 new tags, removed 28, and consolidated or renamed many others — the most significant Steam taxonomy change in years for the recommendation engine.
  • If you have shipped games, re-audit your tags immediately: removed or renamed tags can silently degrade placement in discovery queues and browse algorithms without any notification.
  • New tags reflect 2026 player vocabulary around emergent sub-genres (factory builders, extraction shooters); aligning to current player search terms is a zero-cost discoverability lift.
  • This also affects wishlists in flight — games with stale or low-specificity tags will see reduced algorithmic push even if quality and review scores are strong.

New Open-Source Physics Engine For Blender Released

80 Level
  • ZOZO's Contact Solver is a penetration-free simulation engine for Blender — open-source, so the algorithm is fully auditable and portable to custom engine integrations.
  • Penetration-free contact resolution is a hard unsolved problem in real-time physics (most game engines approximate it aggressively); having a reference-quality solver available for study is a meaningful resource for engine developers.

This Simple Tip Can Make Your Character Animations Feel More Natural

80 Level
  • Gogan's technique focuses on secondary motion layering — adding subtle asymmetric offset to mirrored animation channels to break the mechanical symmetry that reads as artificial.
  • Secondary motion (hair, clothing, limb follow-through) is one of the highest-impact, lowest-cost animation quality improvements: it requires no new keyframes, only curve adjustments on existing channels.
  • This maps directly to procedural animation systems: the same asymmetric noise offset principle can be applied in code at runtime to blend secondary layers without authoring additional animation assets.
