So, I rewrote my game in C3

Madrigal Games
  • Madrigal ported Traction Point (about 100k lines) from Zig to C3, cutting full debug builds from about 24s to about 3s on Windows.
  • The port went one system at a time through the game's WASM modding SDK while the Zig version kept running.
  • The studio also built SL3, a C3 subset that runs on a register VM or compiles to a native DLL and drives its particle editor.

Show HN: A 52 KB WebAssembly engine that runs Qwen3.5-2B in a browser tab

Hacker News Game Dev
  • A 52 KB Zig-to-Wasm engine runs Q4_K_M Qwen3.5-2B at about 39 tok/s on an M3 Max, roughly 65-75% of native llama.cpp CPU speed.
  • Prompt processing is the weak spot (about 160 vs 513 tok/s) because tokens are handled one at a time.
  • Qwen3.5-2B needs about 1.4 GB of memory, with no server, GPU or API key.
