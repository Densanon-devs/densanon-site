Show HN: Hello Triangle, a puzzle game where you build a GPU

Hacker News
  • Players wire adders, comparators and registers into circuits that draw a target picture; circuits cannot contain loops, so counting requires building a counter from a register and an adder.
  • Parts you finish are reused in later levels, so a slow or large part raises area, delay and cycle count everywhere it appears. Clicking a wrong pixel rewinds to the cycle that drew it so every wire value can be inspected.
  • The free demo (Act 1, 16 levels) ends with drawing a triangle on Steam and itch.io; Act 2 (17 levels, ending in a 3D cube) is planned for Early Access in early 2027.

Show HN: IndexFast - see which of your pages search engines actually know about

Hacker News
  • It watches a sitemap and automatically submits new or updated pages to IndexNow engines (Bing, Yandex, Naver, Seznam, Yep), batching up to 1,000 URLs per IndexNow request.
  • On HTTP 429 a circuit breaker pauses a site's jobs for 1 hour, doubling up to 24 hours; retries use exponential backoff with plus or minus 20% jitter and honor Retry-After.
  • It ships an MCP server, REST API and CLI (npx indexfast). The page states Google does not accept IndexNow and indexing there cannot be guaranteed; plans are Free, Pro ($19/30 days) and Unlimited ($99/30 days).

Techniques & Learning

Proof Number search: exhaustively search a game tree to prove win or lose

minimax.dev
  • Proof number search is a best-first AND/OR tree search that proves or disproves a position rather than picking the best move; a forced draw counts as a loss for the attacker.
  • Each node tracks proof and disproof numbers: an OR node's pn is the minimum of its children's and its dpn the sum; an AND node is the reverse. The search descends to the most-proving leaf, expands it and backpropagates until the root is solved or the budget runs out.
  • Results depend heavily on the node initialization heuristic (pn = dpn = 1 is the conservative default), and memory use is the practical limit. The page links a Rust implementation for Ultimate Tic Tac Toe.

A Pile of MCP Connectors Is Not a Context Engine

Unblocked
  • The post argues per-system MCP connectors give agents access but not cross-tool understanding: the agent must assemble sources itself, cannot tell which source is current, and each connector adds its own credentials and permission model.
  • A context engine instead resolves aliases and cross-system links at ingestion, reconciles contradictions with recency and authority signals, enforces permissions server-side, and returns cited answers.
  • Vendor benchmarks claim up to 83% faster and 48% fewer tokens on a Kotlin SDK task; these are the author's own and unverified. The post concedes connectors remain right for transactional actions.

Community Highlights

Amass v5 silently ignores -alts and -brute: flags never cross the engine API

Medium
  • In Amass v5 the CLI POSTs its config to a separate engine that unmarshals into a zero-valued struct; the six alteration-technique fields (FlipWords, FlipNumbers, AddWords, AddNumbers, MinForWordFlip, EditDistance) were tagged json:"-", so they never reached the engine and the tool exited 0 with no alterations.
  • The author's fix gives those fields real JSON names (PR #1161). The existing exact-JSON config test had pinned the buggy output, so it could not catch the problem.
  • Separately, v5 has no wordlist brute-force plugin at all (issue #1122), and an engine log filename containing colons fails on Windows (PR #1160).
