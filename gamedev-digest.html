How information theory saved my word game

Hacker News Game Dev
  • The developer applied information-theoretic principles — entropy and expected information gain — to score and guide player guesses, giving the game a mathematically grounded feedback loop.
  • This technique, popularized by Wordle solvers, adapts to any game mechanic where players narrow a solution space: puzzle, deduction, and hidden-information titles all benefit.
  • The writeup is a practical example of borrowing rigorously from adjacent fields to solve a game feel problem rather than relying on gut instinct alone.

A wire-faithful, browser-based re-creation of the Atari ST game MIDI Maze

Hacker News Game Dev
  • MIDI Maze (1987) was one of the first networked multiplayer games, linking Atari STs via MIDI cables — this JavaScript port preserves that wire-faithful networking model in the browser.
  • The project is a strong case study in faithfully emulating original network protocols and game logic, useful for anyone interested in game preservation or historical multiplayer architecture.
  • Running entirely in the browser makes it accessible without setup, lowering the barrier for researchers, educators, and retro enthusiasts to study this landmark piece of multiplayer history.
