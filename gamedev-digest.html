Open-source AnyPS5 dumps emulation to run PS5 games natively on PC

Hacker News Game Dev
  • AnyPS5 is an open-source project aimed at running PS5 games natively on PC rather than through traditional full-system emulation.
  • It leverages the PS5's AMD Zen 2 architecture, which is close enough to PC hardware to enable Proton-like binary translation instead of CPU emulation.
  • The approach targets both Windows and Linux, mirroring the binary-translation strategy Valve's Proton uses for Windows games on Linux.
