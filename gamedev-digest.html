Unity & Unreal Change The Way You Access Assets

Game From Scratch
  • Unity's new Asset Library plugin (Unity 6.x and 7) lets developers download individual assets from a pack, including free and already-owned ones, instead of the whole bundle.
  • It works with the Unity CLI to split the old .unitypackage format, bringing Asset Library access to the command line and AI agents.
  • Unreal Engine 5.9 Preview 2 exposes Fab to AI agents via MCP and adds seller search and more search filters.
