This Language-Based Puzzle Game Is Hand-Painted in Watercolor

80 Level
  • The Land Forgotten is a work-in-progress point-and-click puzzle adventure by developer Daria, in which apprentice Qoli and her companion Rat search for a lost civilization to translate a manuscript.
  • Puzzles are built on real-world languages and linguistic principles, with writing and number systems appearing as keys, spells, and potion ingredients; the keys, for example, draw on a Mongolian writing system.
  • The art is entirely hand-painted in real watercolor: backgrounds are composed first, several palette sketch variants are made, and characters are animated frame by frame with each frame painted.

This Tool Speeds Up Texturing Workflow Between Painter & UE5

80 Level
  • Moss3D's TexBridge exports textures from Substance 3D Painter, imports them into Unreal Engine 5, creates a Material Instance per texture set, and can assign them to selected Static Meshes in one Export + Send click.
  • It applies per-map compression and sRGB settings (such as disabling sRGB for packed ORM masks) and converts OpenGL normals to DirectX.
  • It needs Painter 8.3 or later and UE5 on Windows on the same machine, uses Unreal's Python Remote Execution so no plugin is needed, and supports shareable profiles for export settings and material mappings.
