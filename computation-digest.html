Samsung shows first HBM5 mockup with Heat Path Block cooling — thermal race with SK hynix shaping up

Tom's Hardware
  • Samsung's HBM5 mockup debuts a Heat Path Block structure that routes heat out of the stacked die package, addressing the thermal bottleneck that limits sustained AI workload bandwidth on HBM4.

Intel Preps GCC Function Multi-Versioning To Support APX & AVX10.2

Phoronix
  • New GCC patches add Function Multi-Versioning (FMV) dispatch for AVX10.2 and Intel's Advanced Performance Extensions (APX), letting a single binary ship optimized hot-paths that activate at runtime based on detected CPU features.
  • Separate GCC tuning work for Nova Lake and Diamond Rapids explicitly disables some APX capabilities that showed negative performance impact, indicating the ISA extensions are not universally beneficial without profiling.
  • FMV support is the upstream compiler prerequisite before distro-packaged software can realistically exploit these instruction sets on next-generation Intel server chips.

New "KRAID" Compiler Merged To Mesa For Panfrost/PanVK Drivers

Phoronix
  • KRAID, a new compiler backend targeting modern Arm Mali GPUs, has been merged into Mesa 26.2 and will serve both the Panfrost (OpenGL) and PanVK (Vulkan) open-source driver stacks.
  • The compiler is designed specifically for the CSF (Command Stream Frontend) architecture used in recent Mali GPUs, replacing older compiler paths that were not architected for these ISA characteristics.
  • Landing in Mesa 26.2 means KRAID will be available to distributions shipping the next Mesa stable series, directly improving GPU performance and compatibility on Arm-based Linux devices and SBCs.
