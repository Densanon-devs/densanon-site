The Very Exciting Cache Aware Scheduling Looks Like It Will Land For Linux 7.2

Phoronix
  • Cache Aware Scheduling (CONFIG_SCHED_CACHE) is expected to merge in Linux 7.2 — a long-awaited kernel scheduler enhancement years in development.
  • CAS helps the scheduler make smarter placement decisions by modeling CPU cache topology, reducing cache-thrash on multi-socket and hybrid-core systems.
  • This has direct performance implications for HPC, database, and latency-sensitive workloads previously hurt by cache-oblivious scheduling.
