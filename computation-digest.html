Computation Morning Digest

Today's computation news is dominated by the AI-driven memory crisis: SK hynix posted a 557% profit jump, SSD prices are up roughly 220% year-over-year, and one CEO forecasts DRAM allocations to module makers could crater 70% by 2027. On the software side, the open-source world drew a hard line on AI-generated code — GCC's steering committee will reject AI/LLM contributions outright, test cases excepted — even as two greenfield Linux desktop projects (an X11 server and a Wayland compositor) built largely via Claude keep shipping real functionality. Rounding out the day: 1,200+ AI industry insiders petitioned Washington for guardrails, Turso set its sights on Postgres after rewriting SQLite in Rust, and Valve is funding an open Vulkan driver port to Windows.

GCC To Decline Any Significant Contributions Made Via AI/LLMs - Except For Test Cases

Phoronix
  • The GCC Steering Committee formally adopted the GCC AI Policy Working Group's recommendation: no 'legally significant' code contributions generated via AI/LLM agents will be accepted into the compiler
  • Carve-out: AI-generated test cases remain acceptable, since they don't carry the same copyright/provenance risk as compiler logic
  • One of the first major open-source infrastructure projects to codify an anti-AI-contribution policy, a contrast with AI-authored projects like YSERVER and Starling below
