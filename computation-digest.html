Claude nukes a developer's 700 GB home directory while testing deletion safeguards; automatic model safety downgrade may have contributed to the screw-up — Anthropic safety harness downgraded model to Opus 4.8 before fatal variable collision

Tom's Hardware
  • A developer testing a script specifically meant to verify Claude would NOT delete files watched it wipe a 700 GB home directory instead.
  • Anthropic's safety harness had auto-downgraded the session to Opus 4.8 mid-task; the weaker model appears to have mishandled a variable collision in the test script that triggered the deletion.
  • Real risk for anyone running agentic coding tools with filesystem access: model routing/downgrades can change behavior mid-session without the user noticing.

AMD Preparing To Enable HDMI 2.1 FRL Support By Default For Linux

Phoronix
  • AMD is preparing to enable HDMI 2.1 Fixed Rate Link (FRL) support by default in the open-source AMDGPU Linux driver.
  • FRL patches were first posted back in May; for years open-source HDMI 2.1 support was blocked by HDMI Forum licensing restrictions, not a technical limitation.
  • Once default, Linux users get full HDMI 2.1 bandwidth without manual driver flags — relevant for 4K/120Hz+ and high-refresh displays on AMD GPUs.

Chris Mason Steps Down As Btrfs Co-Maintainer, Departing Meta

Phoronix
  • Longtime Linux kernel developer Chris Mason, Btrfs's original author, is leaving Meta and stepping down as Btrfs co-maintainer.
  • Mason has been a fixture of Btrfs maintenance since creating the filesystem at Oracle in 2007.

Linux 7.3 Will Begin Checking USB-C Cables For Alt-Mode Support

Phoronix
  • Linux 7.3 merges USB subsystem changes that check USB-C cables for Alt-Mode support — closing a long-standing gap where the kernel couldn't tell whether a plugged-in cable actually supported the mode being negotiated.
  • Also merged: a new low-latency USB4STREAM option for the USB4/Thunderbolt stack.
  • Practical effect: fewer silent failures from using a charge-only or low-spec USB-C cable for DisplayPort/Thunderbolt alt modes.
