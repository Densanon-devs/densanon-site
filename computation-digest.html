Linux 7.2 Ready With IMA and EVM Post-Quantum ML-DSA Signature Support

Phoronix
  • Linux 7.2 adds ML-DSA (Module-Lattice Digital Signature Algorithm) support to the IMA and EVM integrity subsystems, enabling post-quantum-secure boot and file integrity verification.
  • ML-DSA is a NIST-standardized post-quantum signature scheme, making this one of the first major OS kernels to ship native PQC integrity infrastructure in the mainline.
  • The change is forward-looking: current quantum computers cannot break RSA/ECDSA, but 'harvest now, decrypt later' attacks make migration planning urgent for long-lived systems.
  • IMA/EVM are used in high-assurance Linux deployments in government and enterprise, so PQC support here has immediate practical relevance for those environments.

Linux 7.2 Protects Against Crafted Perf Data From Going Rogue

Phoronix
  • Linux 7.2 adds protections to the perf tool to guard against specially crafted or corrupted performance data files that could cause system instability or privilege escalation.
  • The perf tool runs with elevated privileges to access hardware performance counters, making it a meaningful attack surface if malformed data can be fed to it.

QSOE v0.1 Released As A QNX-Inspired RISC-V OS

Phoronix
  • QSOE 0.1 is a new open-source operating system targeting RISC-V, inspired by QNX's dual-kernel microkernel architecture.
  • The dual-kernel design separates real-time and general-purpose workloads at the OS level, a pattern valued in embedded, automotive, and industrial control applications.
  • Targeting RISC-V exclusively positions QSOE in the growing open-ISA embedded systems space where QNX's commercial licensing is a barrier.
  • At v0.1 this is early-stage, but it addresses a genuine gap: there are few open-source microkernel OSes purpose-built for RISC-V with real-time capability.
