Open-source stealth USB hides an encrypted partition behind an 8GB decoy drive

Tom's Hardware
  • 'Phantom Drive' presents as an ordinary 8GB drive until a specifically named text file containing the password is written to it, which triggers the hidden partition to mount.
  • The password never touches flash storage — custom firmware intercepts it in transit and hashes it directly in the microcontroller's SRAM, leaving no on-disk credential trace.
  • A practical plausible-deniability storage design built entirely on cheap, commodity USB microcontroller hardware and open-source firmware.

Mesa 26.3 Intel Driver Code Enables Large GRF Mode For Newer GPUs

Phoronix
  • Large GRF (general register file) mode increases per-thread register allocation on Intel's Alchemist/DG2 and Battlemage/Xe2 GPUs, reducing register spilling during shader compilation.
  • The same patch set adds VRT (variable register/thread) support for the next-gen Xe3 architecture — driver groundwork landing ahead of that hardware's mainstream availability.
  • Compiler-level register allocation changes like this typically translate directly into measurable shader throughput gains on register-pressure-heavy compute and gaming workloads.

Matt Kinsella (Infleqtion): Why Neutral Atoms Power Sensors, Clocks, and Computers Alike

The Quantum Insider
  • Infleqtion is building neutral-atom qubit hardware as a shared physical platform across three product lines at once: quantum computing, quantum sensing, and precision timing/clocks.
  • CEO argues the diversification is technically synergistic, not just a business hedge — atom-trapping and control advances made for one product line (e.g., clocks) feed directly into the others (e.g., qubit coherence).
  • Positions neutral-atom architectures against superconducting and trapped-ion competitors, which lack comparable adjacent sensing/timing markets to cross-subsidize R&D spend.
