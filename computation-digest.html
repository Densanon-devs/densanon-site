Ubuntu 26.10 Moves cp, mv & rm Over To Rust Coreutils For 100% Transition

Phoronix
  • Ubuntu 26.10 completes the Rust coreutils migration for cp, mv, and rm, the three utilities that Ubuntu 25.10 and 26.04 LTS had held back on GNU coreutils because of compatibility gaps in the upstream uutils project.
  • Those upstream blockers are now resolved, letting Ubuntu finish swapping these core file-management commands to the memory-safe Rust implementations alongside the utilities already migrated in prior releases.
  • Ubuntu 26.10 stable is targeted for October 15, 2026.

OpenVDB Introduces SIMD Framework With Some 2~4x Performance Improvements

Phoronix
  • OpenVDB 13.1 adds a new SIMD framework built on Agner Fog's VectorClass Library, with explicit x86 intrinsic support up to AVX-512, turned on via the `_USE_VCL=ON` build option.
  • The initial coverage targets point transfer algorithms and delivers 2x-4x performance improvements on modern AVX-512-capable x86_64 CPUs; future releases will extend SIMD coverage to more operations.
  • Ships alongside updates to NanoVDB's CUDA resource management and the vdb_tool command-line utility in the same 13.1 release from the Academy Software Foundation.

Linux 7.4 Slated To Land The AVX-512 Optimized xor_gen For A Big Performance Win

Phoronix
  • Google's Eric Biggers submitted an AVX-512-optimized xor_gen() for the Linux kernel, the function Linux software RAID5/RAID6 uses to generate and validate parity blocks.
  • The optimization targets AMD Zen 4-and-newer and current Intel server CPUs with AVX-512, and showed strong gains in benchmarks run on an AMD Ryzen 9 9950X.
  • Patches are queued in the x86/fpu branch for the Linux 7.4 merge window, expected to open in mid-October 2026.

AMD P-State Driver For Linux 7.4 Will Tune For Zen 6 Client CPUs

Phoronix
  • Linux 7.4's AMD P-State driver adds Zen 6 client CPU tuning, with separate Energy Performance Preference values for performance cores, dense/efficiency cores, and AMD's new low-power core type.
  • Boost ratio calculation switches from an arbitrary performance scale to being derived directly from frequency values.
  • Lands in the same kernel cycle as AMDGPU's default-on HDMI 2.1 (FreeSync/VRR/ALLM) support, ahead of AMD's next-gen Ryzen client launches expected in early 2027.

Tom's Hardware
  • An enthusiast fully reverse-engineered and dumped Sony's PS2 "MechaCon" security chip (part CXP102064) after four years of effort, 26 years after the console's release.

Java 27 Reaches GA With The G1 Garbage Collector By Default Everywhere

Phoronix
  • OpenJDK 27 reached general availability with G1 as the default garbage collector in every environment, not just server deployments (G1 has been the server default since JDK 9).
  • Oracle says G1 is now competitive with the Serial collector across all heap sizes on throughput, latency, memory use, and startup time, which is why it replaces Serial as the universal default.
  • The release also ships Compact Object Headers on by default (96 down to 64 bits, improving heap density), a post-quantum hybrid key exchange for TLS 1.3, plus continued previews of Structured Concurrency and the Vector API.
