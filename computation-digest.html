AMD's legendary K5, its first independently-designed processor, is being removed from the Linux kernel — 4.3-million-transistor chip gets the axe because it lacks Time Stamp Counter (TSC) support, making it a coding burden

Tom's Hardware
  • The AMD K5 — AMD's first fully independently designed x86 processor, introduced in 1996 — will be dropped from Linux support in kernel version 7.2.
  • The concrete technical trigger is the K5's lack of a Time Stamp Counter (TSC), which modern kernel timekeeping and performance subsystems depend on, creating an ongoing maintenance burden.
  • This is a code-hygiene removal rather than a functional regression: no consumer hardware running a K5 is plausibly still in active production use.

Debian Release Team: Debian Must Now Ship Reproducible Packages

Phoronix
  • The Debian Release Team has mandated that all packages in Debian 14 'Forky' must be reproducibly built — meaning a package built from the same source twice must produce bit-for-bit identical binaries.
  • Reproducible builds allow independent verification that shipped binaries match their source code, closing a class of backdoor-insertion and supply-chain attacks.
  • The announcement comes at the midpoint of the Debian 14 development cycle, giving maintainers time to bring non-reproducible packages into compliance before the freeze.
