Researchers create DNA computer that performs 100-bit calculations without electricity

Tom's Hardware
  • Researchers at Maynooth University built a DNA-based computing system that performs arithmetic and 100-bit calculations using molecular reactions instead of electrical power.
  • The system relies on self-assembling DNA strands that encode and process information through complementary base-pairing reactions rather than transistor logic.
  • It demonstrates a working alternative computing substrate for electricity-free or biologically embedded computation, though it runs far slower than silicon.

Apple Video Decode Driver Posted For Upstream Linux Kernel Review

Phoronix
  • The Asahi Linux project submitted its AVD (Apple Video Decode) driver upstream for Linux kernel review, adding accelerated video decode support for Apple M1/M2/M3 SoCs.

Google's 'Painful To Maintain' Binder C Linux Driver Being Removed In Favor Of Rust

Phoronix
  • Google is removing the C implementation of the Binder IPC driver from the mainline Linux kernel in favor of the Rust rewrite developed over the past few years.
  • Binder is the inter-process communication mechanism Android depends on, making this one of the first widely-used kernel drivers to fully transition to Rust.
  • Google cited the C driver's maintenance burden as the reason for retiring it now that the Rust version is considered stable enough for production use.

Steam Frame Making Use Of Zink For OpenGL On Vulkan

Phoronix
  • Valve's Steam Frame VR headset, built on a Qualcomm Snapdragon 8 Gen 3 SoC, uses Mesa's open-source Turnip Vulkan driver for its Adreno GPU.
  • For legacy OpenGL support, the headset runs Mesa's Zink driver, which translates OpenGL calls to Vulkan rather than shipping a native OpenGL driver.
  • The choice confirms Valve is relying entirely on the open-source Mesa graphics stack, Turnip plus Zink, rather than Qualcomm's proprietary drivers for the device.

Intel suspends bug bounty program that paid up to $100,000 per flaw

Tom's Hardware

  • A new Intel vulnerability disclosure program has replaced it on Intigriti, but it offers no financial rewards for reported bugs.
