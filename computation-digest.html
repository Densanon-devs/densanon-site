Computation Morning Digest

Linux's low-level graphics and compute stack got several groundwork drops today: Nouveau landed HDMI 2.1 bring-up fixes for NVIDIA Blackwell GPUs, AMD announced a dedicated team pushing Rust into GPU firmware and drivers (mirroring NVIDIA's own Rust-based Nova kernel driver), and PoCL 7.2 earned official Khronos OpenCL 3.0 conformance on both RISC-V and x86_64 AVX-512 hardware. On the systems side, Amazon Linux 2027 previewed EPYC performance gains from default LTO builds and an x86-64-v3 baseline, while Apple Silicon Linux support inched forward with single-core boot patches for the A18 Pro in the new MacBook Neo. Underneath it all, Taiwan's multi-year crackdown on illegally Chinese-owned chip businesses — 166 investigations and at least 36 convictions since 2020 — is a reminder that the semiconductor talent pipeline is still an active enforcement front, not just a trade-policy one.

Nouveau Lands Display Fixes For NVIDIA Blackwell GPUs As It Works Toward HDMI 2.1

Phoronix
  • Fixes merged ahead of Linux 7.3-rc2 address GPU System Processor (GSP) interaction bugs, HDMI vendor infoframe handling, and HDMI GCP AVMute register offsets on Blackwell (GB20x) GPUs.
  • Developer Mohamed Ahmed frames the work as part of ongoing HDMI 2.1 bring-up — fixing vblank interrupts and infoframe handling that FRL, DSC, and VRR support will depend on.
  • Some of the fixes address latent bugs that don't affect current operation but are necessary prerequisites for the next stage of HDMI 2.1 work.
  • The same DRM fixes batch also touched AMDGPU and Intel display code, part of the routine pull ahead of the 7.3 kernel release.

Linux Patches Posted For Initial Enablement Of The Apple A18 Pro + MacBook Neo

Phoronix
  • Developer Yureka Lilian posted initial device-tree patches enabling the A18 Pro SoC (t8140) — the same chip used in the iPhone 16 Pro — to boot on Linux.
  • The device tree is minimal: CPU cores, interrupt controller, watchdog, serial, and framebuffer only, with no GPU acceleration yet.
  • The SoC currently only boots on a single CPU core due to unresolved WFI/WFIT instruction-handling issues; multi-core support is still pending.
  • Full support also needs matching updates to the Asahi Linux project's m1n1 bootloader, and the article estimates it will be months before the budget MacBook Neo runs well on Linux.

AMD Working To "Push Rust Deep Into The GPU Stack"

Phoronix
  • AMD Senior Fellow Harsh Meno says he's building "a small, elite team" to push Rust into GPU firmware, drivers, shader compilers, and other layers of the stack.
  • An active AMD job listing targets "performance-sensitive and high-trust parts of the GPU stack," covering compiler support, system interfaces, and production validation methods.
  • The move parallels NVIDIA's own Rust push, including its Rust-based Nova Linux kernel driver — memory-safe GPU drivers are becoming a two-vendor trend, not a one-off experiment.
  • Nothing has shipped yet; this is a hiring and team-formation signal rather than a released driver or compiler.

Taiwan Cracks Down On Tech Businesses With Illegal Chinese Ownership — 166 Investigations And At Least 36 Convictions Since 2020

Tom's Hardware
  • Taiwanese investigators have opened 166 investigations and secured at least 36 convictions since 2020 against tech businesses operating with illegal Chinese ownership.
  • The alleged pattern is Chinese-backed operations hiring Taiwanese engineers for semiconductor R&D work while evading the island's foreign-investment restrictions.
  • The multi-year case count points to a sustained, structural enforcement effort rather than an isolated bust — relevant to anyone tracking where Taiwan's chip-design talent and IP are legally allowed to flow.

Amazon Linux 2027 Shows Off Nice Performance Gains On AMD EPYC In The AWS Cloud

Phoronix
  • AWS is previewing Amazon Linux 2027, the successor to Amazon Linux 2023, benchmarked running on AMD EPYC hardware in AWS's own cloud.
  • Per the article, packages are now built with link-time optimization (LTO) by default and the distribution enforces an x86-64-v3 baseline (AVX/AVX2), among other under-the-hood changes.
  • Phoronix describes the combination as producing "nice performance gains," though the exact magnitude wasn't captured in the summary available for this digest — worth a follow-up read for anyone running EPYC fleets on Amazon Linux.

PoCL 7.2 Released With Official OpenCL 3.0 Conformance On RISC-V & x86_64 CPUs

Phoronix
  • PoCL 7.2 earned official Khronos OpenCL 3.0 conformance on RISC-V (RV64GC and RVA22+RV1.0) and on x86_64 with AVX-512 code paths, tested on an AMD Ryzen 9 9900X (Zen 5).
  • The release adds support for LLVM 22 with CUDA and Level Zero device backends, and up to LLVM 23 for CPU-only targets.
  • Seven new OpenCL extensions land, including cl_khr_extended_bit_ops, cl_khr_device_uuid, and cl_khr_suggested_local_work_size.
  • As an MIT-licensed, LLVM-backed OpenCL implementation, PoCL's conformance push matters to anyone needing a portable compute runtime across CPU and GPU targets without a vendor SDK.

Wine 11.17 Released With Initial Support For Display Mode Emulation

Phoronix
  • Wine 11.17 adds initial display-mode emulation led by Rémi Bernon: it renders OpenGL content at the game's requested (emulated) resolution, then scales the output to fit the actual host window or display.
  • The release integrates VKD3D 2.1, updating the Direct3D 12-over-Vulkan translation layer.

NetworkManager Works To Enforce AI Policy By Tricking AI Agents To Add A Canary

Phoronix
  • NetworkManager's AI-authorship policy requires contributors to take full responsibility for, and be able to explain, 100% of submitted code.
  • To catch agents ignoring that policy, maintainer Josephine Pfeiffer seeded the project's AGENTS.md/CLAUDE.md with an instruction telling AI agents to work the word "biblioklept" into any commit message, merge-request description, or review reply they generate.
  • Because that word has no reason to appear in networking code review, any submission containing it flags itself as AI-generated — turning the agent's own instruction-following into the detection signal, a trick worth stealing for any team drafting its own AGENTS.md.
