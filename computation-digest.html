Anthropic won't fix a Claude Dispatch flaw that could let attackers execute remote commands across corporate boundaries

The Register
  • Researcher Gal Weizman of Forever Security found that Dispatch was reachable from an ordinary logged-in claude.ai session, so a malicious browser extension could send commands to Claude Desktop as the user (dubbed 'ThisBash').
  • The six-step chain uses the user's session cookies, a hidden popup and scripted 'Allow' clicks to get the agent to install and run a malicious npm package.
  • Anthropic closed the May report as a duplicate, paying no bounty and issuing no CVE, and said it planned to retire Dispatch at the end of October; it did not answer The Register's questions.

New York's Queens Public Library battles ransomware crims: Wi-Fi, checkouts, and website go dark

The Register
  • Queens Public Library confirmed a ransomware attack that took down its website, on-site computers, check-out and return machines, public Wi-Fi, mobile app and digital media services.
  • Branches remain open, but the library warned restoration will take time; no established ransomware group had claimed the attack at the time of reporting.
  • The Register points to the British Library's 2023 Rhysida attack as the comparison: it refused a 20 Bitcoin ransom, and its recovery is still incomplete.

Unlocking Turing Tensor Cores: A Measured Throughput Account of From-Scratch Pre-training on a Single 22G RTX 2080 Ti

ArXiv CS (Architecture + Distributed + Performance)
  • The turing-unlock module lifts the driver-level FP16 throttle on the RTX 2080 Ti, raising cuBLAS FP16 matmul throughput from 55.7 to 91.4 TFLOPS (about 1.6x).
  • Training a 75.7M-parameter model improved from 6,480 to 7,246 tok/s (+11.8%), saving 9.0% wall time; the smallest tiers gained at most +0.3%.
  • Peak memory is bit-identical and final quality metrics differ by no more than 10^-3.
