Phoronix

Linux Erroneously Thinks Intel Bartlett Lake CPUs Run At 7GHz

Phoronix
  • The Intel P-State driver misreports Bartlett Lake (embedded P-core-only) CPUs as running above 7.0 GHz — a driver bug, not actual clock speed.
  • Bartlett Lake is Intel's latest embedded-market processor; the 7 GHz report affects Core 9 273PE and likely other SKUs in the family.
  • The bug is visible in system monitoring tools and could cause incorrect thermal/power policy decisions by the OS scheduler.

Dirty Frag Vulnerability Made Public Early: Root Privilege On All Distributions

Phoronix
  • Dirty Frag is a local privilege escalation bug in Linux that grants root on all major distributions — no patches or CVEs are available yet.
  • The embargo was broken early by the researcher, meaning the vulnerability is now public before any coordinated fix has landed.

DM-INLINECRYPT Expected For Linux 7.2 To Leverage Inline Encryption

Phoronix
  • A new dm-inlinecrypt device-mapper target is queued for Linux 7.2, allowing block device encryption to be offloaded to hardware inline encryption engines.
  • This reduces CPU overhead for storage encryption on hardware that supports inline crypto (common on mobile SoCs and newer NVMe controllers).
  • The change lands in the DeviceMapper subsystem and is targeted for the 7.2 merge window.
