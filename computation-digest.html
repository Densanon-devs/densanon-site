Alibaba Contributing $3M USD To Omarchy To Work On Making "Ideal" Agentic OS

Phoronix
  • Alibaba Cloud is contributing $3 million total to the Omacom Foundation for Omarchy, a Linux distribution positioned as a desktop OS built for people and AI agents to work together, matching DigitalOcean's existing $1 million-per-year commitment over three years.
  • Alibaba will also stand up a separate 'Omarchy China' effort for local CDN, hosting, and meetups, and plans to tune the OS specifically for its own Qwen models plus integration with Chinese cloud services.

ZLUDA Now Implements Some NVIDIA cuFFT APIs With hipFFT

Phoronix
  • ZLUDA, the open-source layer that runs CUDA software on non-NVIDIA GPUs, added support for a subset of NVIDIA's cuFFT fast-Fourier-transform APIs in its 7-preview.11 release, contributed by developer AmosKito1.
  • The implementation only covers cuFFT calls that have a direct equivalent in AMD's own hipFFT library (part of ROCm/HIP), so it is partial coverage rather than a full cuFFT reimplementation.
  • The translation layer was enough to get Folding@Home's Core24 and Core27 CUDA compute cores running on AMD Radeon hardware, per Phoronix.

Linux Adding New Interface For Reporting AMD SEV Status

Phoronix
  • A new sysfs file, /sys/devices/system/cpu/sev/sev_status, is being added to Linux to report whether AMD Secure Encrypted Virtualization is active on a guest VM, along with higher-level capability flags for SEV-ES and SEV-SNP.
  • The interface reads the SEV_MSR register directly, letting users check encryption status without external tools like sevctl or snpguest.
  • It is queued for Linux 7.4, whose merge window is expected to open around October 2026 -- notable mainly because the gap existed this long despite SEV shipping in hardware for years.

Cache Aware Scheduling Fixes Queued For Submission To Linux 7.3, Backporting To 7.2

Phoronix
  • Intel engineer Tim Chen queued a batch of Cache Aware Scheduling (CAS) fixes in the sched/urgent branch of tip/tip.git, targeting Linux 7.3 this week with a backport planned for 7.2, where CAS first landed.
  • The fixes cover correctly maintaining nr_pref_llc_running per runnable domain, honoring migrate_llc_task semantics during active load balancing, refreshing last-level-cache capacity across CPU hotplug events, and excluding kernel threads from cache-aware placement.
  • CAS groups related tasks onto cores sharing the same last-level cache to cut cache-bouncing latency; these are correctness fixes for that existing mechanism, not a new feature.

Patches Posted For Enabling Apple Silicon Mac Speaker & Headset Jack Support On Linux

Phoronix
  • James Calligeros posted 28 patches, roughly 3,000 lines, for mainline kernel review to bring speaker and headset-jack audio to Apple M1 and M2 Macs running Linux; M3 support is deferred because prerequisite hardware nodes are still missing upstream.
  • The functionality already exists downstream in the Asahi Linux kernel -- this submission is the effort to mainline it into vanilla Linux rather than keep it as a downstream patch set.
  • A new 'macaudio' machine driver handles speaker protection through a userspace daemon, speakersafetyd, which reads voltage and current telemetry to keep the Macs' fragile speakers from being damaged.

AMD Begins Preparing Open-Source Linux Driver For Graphics Cards With GDDR7

Phoronix
  • AMD sent kernel patches adding GDDR7 as a recognized video-memory type in the AMDGPU driver, alongside new IP-block support for IH 8.0 (interrupt handler) and NBIF 7.10 (bus interface), pointing at upcoming RDNA5 hardware.
  • Current RDNA4 cards use GDDR6; the GDDR7 enablement follows recent DCN6 display-core and GFX 13.0.x patches and confirms RDNA5 will switch memory types, aligning with Nvidia's RTX 50-series approach.
  • Industry rumors cited by Phoronix put limited RDNA5 SKUs at a 2027 launch with broader availability slipping to 2028 on supply constraints, so this driver work is well ahead of actual silicon.

Valve Introduces Pyrowave Video Codec In Beta For Low Latency Streaming

Phoronix
  • Valve engineer Hans-Kristian Arntzen's Pyrowave, a new Vulkan-based video codec for Steam Remote Play, rolled out in experimental beta on September 21 across Windows, macOS, and Linux via the SteamRT3 Steam client beta.
  • It targets low-latency LAN streaming over Gigabit Ethernet and supports HDR and YUV 4:4:4 color, but Phoronix notes it uses 5 to 10x the bandwidth of existing streaming codecs to get there -- a deliberate responsiveness-over-efficiency trade.
  • It is opt-in via the Remote Play advanced client settings in the Steam beta, not enabled by default.

China's CXMT hits 12nm-class DRAM milestone

Tom's Hardware
  • China's DRAM champion CXMT has begun mass production on a 5th-generation DRAM process it describes as 12nm-class, using quadruple-patterning lithography.
  • Tom's Hardware reports the new process boosts die capacity by about 50 percent over the prior generation.
  • CXMT is China's leading domestic DRAM producer, so the milestone marks continued progress in the country's push toward memory self-sufficiency.

Tom's Hardware
  • DRAM makers may now be earning more revenue per wafer area than TSMC earns on its leading-edge N3 logic process, according to Tom's Hardware -- a reversal of the usual pricing hierarchy between memory and cutting-edge compute silicon.

Raspberry Pi locks boards to factory RAM capacities in firmware

Tom's Hardware
  • Raspberry Pi has locked its boards in firmware to their factory-configured RAM capacity, blocking DIY attempts to swap in higher-capacity memory chips for repairs or upgrades.
  • A Raspberry Pi engineer told modders not to bother trying, and the company cited 'shady reseller scams' -- boards misrepresented as higher-capacity than they actually are -- as the reason for the lock.
  • The change closes off a repair and upgrade path hobbyists had previously relied on for single-board computers.
