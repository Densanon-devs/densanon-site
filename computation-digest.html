GCC 17 Compiler Adding "-m128bit-atomic" For 128-bit Atomic Memory Operations

Phoronix
  • GCC's Git development branch merged a new "-m128bit-atomic" compiler option targeting next year's GCC 17 release.
  • The flag enables 128-bit atomic memory operations, relevant to concurrent data structures and lock-free code needing wider atomic guarantees than 64-bit CAS provides.
  • A low-level toolchain change rather than an end-user feature, but one that opens new patterns for systems programmers on architectures with 128-bit atomic support.

Tom's Hardware
  • Security researchers built a coin-sized device that plugs into an easily accessible diagnostic port in a 737's avionics bay and feeds false data to the Flight Management Computer.
