GCC Patch Adjusting AMD Zen 5 Misprediction Cost Nets 12% Win In Benchmark

Phoronix
  • An AMD compiler engineer posted a two-line GCC patch adjusting the branch misprediction cost model used for Zen 4 and Zen 5.
  • The change yields a 12% improvement on one SPEC CPU benchmark for Zen 5 and 9% for Zen 4.

Redox OS Switches To EEVDF-Based Scheduler For 2.6x Throughput

Phoronix
  • The Rust-written, from-scratch Redox OS switched its process scheduler to an EEVDF-based design, the same family of algorithm Linux's CFS replacement uses.
  • The project reports a 2.6x increase in throughput and a 782x improvement in scheduling fairness over the prior scheduler.
  • A concrete case of a community OS adopting modern scheduling theory to close the gap with mainstream kernels.

ReactOS Merges Support For Job Objects As Step To Running Modern Windows Apps

Phoronix
  • ReactOS merged initial support for Windows Job Objects, the Win32 mechanism for managing groups of processes as a unit.
  • Job Objects are used by many modern Windows applications and sandboxing/container-style tooling, making this a meaningful compatibility milestone.
  • Moves the open-source, Windows-compatible OS a step closer to running more contemporary Windows software unmodified.

Longtime Linux CIFS/SMB3 Maintainer Passes Away

Phoronix
  • Steve French, the principal author and longtime maintainer of Linux's CIFS/SMB3 filesystem code, has stepped down due to health reasons as of Linux 7.3.
  • French was also a Microsoft employee, notable given his role maintaining the kernel's implementation of Microsoft's own SMB3 protocol.
  • Marks a significant maintainership transition for a widely used piece of Linux's network filesystem stack.
