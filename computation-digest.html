Ajinomoto reportedly cuts critical chip packaging film supply to China by 30% as domestic substitutes race to qualify — ABF restriction comes following Beijing's rare earth export curbs

Tom's Hardware
  • Japanese chemical maker Ajinomoto is reportedly cutting supply of ABF (Ajinomoto Build-up Film), a critical chip-packaging insulation material, to mainland China by 30%.
  • The move follows Beijing's rare-earth export curbs, pointing to a tit-for-tat materials squeeze running through the chip supply chain.
  • Chinese chipmakers are racing to qualify domestic ABF substitutes to cover the shortfall — a reminder of how concentrated the advanced-packaging materials supply chain still is.

New AMD Low-Power Core & Unified Intel/AMD CPU Core Type Handling In Linux 7.3

Phoronix
  • Linux 7.3 merges AMD's new "low power" CPU core type, joining the existing "performance" and "efficiency" (Zen 4C/5C) core classes.
  • The low-power core designation is presumed to target upcoming Zen 6 client chips.
  • The same merge window unifies how the kernel reports CPU core types across both Intel and AMD hybrid processors, simplifying scheduler support for heterogeneous chip designs.

Linux 7.3 Scheduler Improvements: Help For Gaming, Hybrid CPUs, Lower Scheduler Latency

Phoronix
  • Peter Zijlstra's "flatten the pick" patch series overhauls cgroup scheduling — moving it to a single runqueue with new weight-distribution modes ('up', 'max', 'concur', 'tasks') — and showed measurable gaming gains even on old Sandy Bridge + Radeon RX 580 hardware.
  • Vincent Guittot's latency-reduction work targets short-slice task scheduling; cyclictest measurements showed "very significant improvements" in scheduler latency.
  • Cluster load-balancing for asymmetric-capacity (hybrid) CPUs is fixed, and NOHZ balancing now prioritizes fully idle cores — both aimed at heterogeneous Intel/AMD chip designs.

Modular's Mojo Language Now Open-Source Following Qualcomm Acquisition

Phoronix
  • Modular has open-sourced the entire Mojo language under Apache 2.0, having previously only open-sourced the standard library.
  • Mojo targets CPUs, GPUs, and AI accelerators from a single codebase, draws syntax ideas from Rust, and supports two-way interop with Python.
  • The release follows Qualcomm's acquisition of Modular — notable given Qualcomm's historically closed licensing reputation. Mojo runs on macOS and Linux today, with Windows support in development; founder Chris Lattner (LLVM, Swift) remains involved.
