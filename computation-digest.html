Researchers build a $7 smartphone clip-on that spots hidden cameras

Tom's Hardware
  • Korean researchers built a sub-$7 hardware clip-on paired with an AI phone app that hits 94% accuracy detecting hidden cameras.
  • It works by cycling a dynamic LED grid across different angles and using AI to distinguish lens reflections from ordinary surfaces, rather than relying on IR-only detection.

GCC 17 Compiler Merges Initial Support For Intel/AMD AI Compute Extensions "ACE"

Phoronix
  • GCC 17 lands initial support for ACEv1 (AI Compute Extensions), a joint Intel/AMD matrix-acceleration ISA effort from the x86 Ecosystem Advisory Group.
  • It's the first cross-vendor standardized instruction set aimed at accelerating AI/ML workloads directly in future x86 CPUs, rather than only via discrete accelerators.
  • Toolchain-level support landing this early signals hardware implementations are coming in upcoming Intel and AMD CPU generations.
