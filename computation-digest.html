Micron discontinues 2GB GDDR7 chips for gaming GPUs as it pivots toward higher-density memory for AI

Tom's Hardware
  • Micron is reportedly ending production of 2GB GDDR7 chips, the memory density used in current gaming graphics cards.
  • The chipmaker is shifting capacity to higher-density 3GB GDDR7 parts, which command better margins in professional and AI-focused GPUs.
  • Gaming GPU makers lose a memory supplier as Micron chases the more lucrative AI accelerator market, adding to the ongoing GDDR7/DRAM supply squeeze.

ASML says it sold 'absolutely nothing' in Europe in 2026

Tom's Hardware
  • ASML says its share of revenue from European customers dropped to essentially 0% in 2026.
  • The lithography giant is calling on EU authorities to help create domestic demand for European-made chips rather than relying on exports to Asia and the US.

Linux Kernel Introducing New Taint Due To Fuzzing Bots Yielding Impractical Bug Reports

Phoronix
  • The kernel is adding a new TAINT_FORCED_BIND flag that marks the kernel as tainted whenever the sysfs bind/unbind interface is used to force a driver onto a device.
  • Greg Kroah-Hartman says the change is a direct response to fuzzers like Syzbot randomly binding incompatible drivers to devices and generating bug reports for combinations that would never happen in practice.
  • Tainting on bind/unbind lets maintainers instantly recognize fuzzer-induced reports, and testing tools can use panic_on_taint to stop a fuzzing run the moment it happens.

Mir 2.30 Released Now With Rust Required, Mir Roadmap Published

Phoronix
  • Canonical's Mir 2.30 now hard-requires a Rust compiler to build, dropping the previously optional MIR_ENABLE_RUST flag since Mir now targets Ubuntu 26.04 LTS, which mandates Rust.

"slab_tiny" Boot Option Proposed For Tiny Linux Systems With Very Limited RAM

Phoronix
  • SUSE's Vlastimil Babka proposed converting the compile-time CONFIG_SLUB_TINY option into a runtime "slab_tiny" boot parameter for systems with roughly 16MB of RAM or less.
  • It's a follow-on to the 2022 deprecation and 2023 (Linux 6.4) removal of the old SLOB allocator, which embedded systems relied on for minimal memory footprints.
  • The option is meant strictly for tiny embedded targets -- enabling it on larger systems would hurt performance by disabling per-CPU object caching.
