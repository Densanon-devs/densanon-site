AI coding agents can be tricked into installing malware via 'clean' GitHub repositories

Tom's Hardware
  • Mozilla's 0din security team demonstrated that AI coding agents including Claude Code can be manipulated into executing malicious code by initializing a minimal-looking but weaponized GitHub repository.
  • The attack exploits the agent's helpfulness: when asked to set up a project, it blindly runs install scripts that deliver malware without user confirmation.
  • This highlights a critical trust boundary issue in agentic AI workflows where tool-use autonomy must be paired with stricter sandboxing and command vetting.
