DirectX Support Promoted To Official Target Within LLVM

Phoronix
  • After roughly four years of Microsoft-backed development, the DirectX backend has been promoted to an official target within the LLVM compiler stack.
  • The backend lowers LLVM IR directly into DirectX Intermediate Language (DXIL), the format consumed by Windows DirectX 12 graphics drivers.
  • Official target status means the backend now gets first-class upstream maintenance and testing instead of living as an out-of-tree experiment.

FEX 2609 Released With Speedier JIT Performance, JIT Disk Cache Option

Phoronix
  • FEX 2609 ships as the latest monthly release of the open-source x86_64-on-AArch64 emulator, adding a faster JIT and a new JIT disk cache option.
  • The disk cache avoids re-JITting the same translated code blocks across runs, which should cut cold-start latency for repeat launches.
  • FEX underpins running Steam and Proton-translated Windows games on ARM64 Linux, so JIT throughput gains translate directly into load times and frame rates.

LLVM Merges Support For AMD's RMPCHKD, RMPREAD & RMPOPT Instructions

Phoronix
  • LLVM/Clang has landed support for AMD's RMPCHKD, RMPREAD, and RMPOPT instructions, targeting Zen 5 and newer processors.
  • RMPOPT specifically reduces overhead on the Reverse Map Table (RMP) that SEV-SNP uses for memory encryption and integrity checks on confidential VMs.
  • Compiler support is landing ahead of the corresponding Linux kernel support, which is still in progress, showing the usual toolchain-then-kernel rollout order for new confidential-computing instructions.

Linux Preps For New AMD Zen 6 BTB CTX Isolation Security Feature

Phoronix
  • A newly posted Linux kernel patch reveals a security feature for upcoming AMD Zen 6 processors that isolates Branch Target Buffer (BTB) entries by execution context.
  • BTB context isolation is a mitigation aimed at branch-predictor side-channel attacks, the same family as Spectre-v2 and BHI, stopping one context from poisoning another's branch predictions.
  • Landing kernel support ahead of hardware availability lets distros ship day-one protection when Zen 6 parts actually launch.
